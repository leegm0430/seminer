구성한 동작

  • 포트폴리오 폴더를 1시간마다 확인하고 변경이 있을 때만 반영합니다.

03

막힌 지점과 해결 방법

PowerShell 실행 정책으로 시작 실패

문제 스크립트를 실행할 수 없다는 보안 오류가 발생했습니다.

대응 설정 창과 예약 작업 프로세스에만 RemoteSigned를 지정했습니다. 컴퓨터 전체의 영구 정책은 변경하지 않았습니다.

봇 대화 전 채팅 ID 확인 실패

문제 봇에게 메시지를 보내기 전에 Enter를 눌러 수신할 채팅을 찾지 못했습니다.

대응 직접 만든 봇에게 /start를 보낸 뒤 설정을 다시 실행해 채팅 ID를 확인했습니다.

GitHub 인증 없이 push 실패

문제 비대화형 작업에 저장된 GitHub 로그인 정보가 없어 업로드가 중단됐습니다.

대응 Git Credential Manager에서 본인 계정 인증을 완료한 뒤 이미 생성한 요약을 재사용해 업로드했습니다.

뉴스 출력 형식 오류

문제 첫 시험에서 JSON 스키마 형식 오류로 조사 작업이 시작되지 않았습니다.

대응 출력 스키마를 수정하고 검사를 통과한 뒤 실제 검색을 다시 실행해 저장과 알림을 확인했습니다.

04

무엇을 검증했는가

  • 예약 등록
    세 작업의 설치 결과와 한국 시간 설정을 확인했습니다.
  • 업로드 범위
    임시 원격 저장소에서 기존 변경·스테이징 보류와 다른 파일 보존을 검사했습니다.
  • 다시 실행했을 때
    하루 기록과 HTML 구역의 중복 방지, 동일 내용의 중복 커밋 방지를 검사했습니다.
  • 뉴스 처리
    오전 8시 경계, 기간 밖 기사 제외, 중복 제거, 출처 URL과 HTML 문자 처리를 검사했습니다.
  • 실제 결과
    학습 요약 업로드·Pages 배포, 뉴스 HTML·Markdown 생성, Telegram 전송을 확인했습니다.
  • 확인의 한계
    모든 향후 정기 실행과 AI 요약의 정확성을 보장하는 검사는 아닙니다. 로그와 원문을 계속 확인해야 합니다.
05

계속 실행하려면

PC가 켜져 있고 등록한 Windows 계정에 로그인되어 있어야 합니다
