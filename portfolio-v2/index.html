03 / HOW I TEST

현상을 재현 가능한 기록으로

게임 제작과 테스트에서 적용해 온 확인 순서입니다

01

기준 정리

기획의 규칙과 기대 결과를 먼저 적고, 확인할 화면과 조건을 나눕니다.

02

조건 비교

정상 진행뿐 아니라 재료 부족, 오답, 재사용처럼 결과가 달라지는 조건을 확인합니다.

03

재현·보고

기대와 실제가 다른 지점을 재현 경로와 로그, 화면 자료로 설명합니다.

04

수정 후 재확인

같은 조건으로 다시 확인하고, 연결된 다른 진행에 문제가 생기지 않았는지 살핍니다.

AI-ASSISTED LEARNING

AI로 만든 결과도 직접 확인합니다

스토리 게임 제작 중 ‘물건 없음·오답·정답·재사용’ 조건의 기대 결과를 실제 플레이와 비교했습니다. 수정한 JSON은 검사를 통과한 뒤 적용하고, 같은 조건으로 다시 플레이했습니다.
