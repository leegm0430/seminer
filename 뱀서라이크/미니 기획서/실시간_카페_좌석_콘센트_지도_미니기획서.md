## 01. 현황분석

### 카공족, 이제는 카페의 '주류 고객'이다

카페에서 노트북을 펴고 공부·업무를 보는 사람들은 더 이상 소수의 취향이 아니라, 카페 매출 구조를 바꾸는 핵심 고객층으로 자리 잡았다.

| 수치 | 의미 | 출처 |
|---|---|---|
| **71%** | Z세대 구직자 중 카페에서 공부한다고 응답한 비율 | 진학사 캐치, 2025.8 |
| **55개** | 카공족 특화 브랜드 '카공족'의 수도권 운영 지점 수 | 데이터뉴스, 2026.3 |
| **87%** | 20대 대학생 중 카페 공부 경험이 있는 비율 | 대학내일20대연구소 |

카공족은 단순히 자리를 오래 차지하는 손님이 아니라, 스스로를 '몰입할 수 있는 공간'을 찾는 소비자로 카페를 재정의하고 있다. (노트북 작업 · 시험·자격증 공부 · 프리랜서·1인 사업자)

> 자료: 진학사 캐치 「카페 공부 실태」 조사(2025.8, Z세대 구직자 2,037명) · 데이터뉴스(2026.3) · 대학내일20대연구소(2017, 대학생 300명)

### 장기 체류 고객이 오히려 매출을 키운다

2025년 주요 카페 프랜차이즈의 구매 데이터는, 카공족처럼 오래 머무는 고객이 카페 매출에 부정적이지만은 않다는 것을 보여준다.

- **전체 구매액**: +11.4%
- **사이드메뉴(식품류)**: +20.7%
- **조리빵류**: +141%

**읽는 법**
- 식사 대용 메뉴(조리빵 등) 구매가 141% 급증 — 장시간 체류·혼밥 트렌드와 맞물림
- 사이드메뉴 성장률(20.7%)이 전체 구매액 성장률(11.4%)을 크게 앞지름
- 1인 장기 체류 고객을 비용 요인이 아닌 매출 기여 고객으로 재평가하는 시각 확대

> 자료: 경향신문, 「'카공족 사절'을 사절합니다」(2026.4.25) — 엠브레인 딥데이터 분석 인용

### 대형 프랜차이즈는 이미 '좌석 설계'로 응답했다

스타벅스·할리스 등은 카공족을 밀어내는 대신, 전용 좌석을 만드는 방향으로 전략을 바꾸고 있다 — 하지만 '정보 제공'은 빠져 있다.

- **스타벅스 '포커스 존'**: 신림녹두거리·세종대점 등 대학가 6개 매장에 1인 좌석·칸막이·개별 콘센트를 갖춘 전용 공간 도입
- **할리스커피**: 카공족을 겨냥해 1~2인용 노트북 작업 전용 좌석을 대거 확충하는 추세
- **카공족(브랜드)**: 일 5,900원 정액에 시간 제한 없이 이용 가능한 카페·스터디카페 결합형 공간, 수도권 55개 지점

> **그러나 세 사례 모두 '어느 매장에 자리가 남아있는지'는 고객이 여전히 직접 가봐야 안다 — 공간은 진화했지만 정보는 그대로다.**

> 자료: 경향신문(2026.4.25), 나무위키 「카공족」 항목

## 02. 문제점

### 이용자: 가봤는데 자리가 없다

콘센트와 좌석 정보를 미리 알 수 없어, 카페를 향한 발걸음이 헛걸음이 되는 경우가 절반에 가깝다.

- **47%** — 카공족 때문에 앉을 자리가 없었던 경험이 '자주/종종' 있다
- **40%** — 카공족이 자리를 오랜 시간 비운 것을 목격한 적 있다

**헛걸음을 만드는 대표 상황**
- 매장은 붐비는데 앉을 자리가 있는지 밖에서 알 수 없다
- 자리는 있어도 콘센트 근처 좌석만 이미 만석인 경우가 흔하다
- 노트북·책만 두고 장시간 자리를 비우는 손님 때문에 '보이지만 못 앉는' 좌석이 생긴다

> 자료: 한국리서치(2021) 카페 이용 실태 조사 — 머니S 재인용(2025.6.11)

### 사장님: 회전율과 매출 사이의 딜레마

장기 체류 손님을 무작정 막을 수도, 그대로 둘 수도 없는 카페 운영자의 현실적인 고민.

**카페 이용 중 '최악의 비매너 카공족' 유형(응답 비율)**

| 유형 | 비율 |
|---|---|
| 자리 맡고 장시간 외출 | 29% |
| 큰 소리 통화·대화 | 25% |
| 음료 한 잔으로 장시간 체류 | 17% |
| 무리한 정숙·자리변경 요구 | 9% |
| 콘센트·좌석 독점 | 8% |

**사장님의 딜레마**
- 회전율을 높이면 손님이 줄고, 그대로 두면 좌석 매출 효율이 떨어진다
- 이용시간 제한, 콘센트 차단, 와이파이 해제 등 '눈치 주기'식 대응은 갈등만 키운다
- 무인주문기 도입률은 2023년 기준 7.8%에 불과 — 결제는 자동화됐지만 좌석 관리는 여전히 수기·눈대중

> 자료: 진학사 캐치(2025.8, Z세대 구직자 2,037명) · 한국농촌경제연구원 「무인주문기 활용의 외식업체 매출·고용영향 분석」(2023년 기준)

### Pain Point 정리: 두 고객의 서로 다른 불편

이용자와 사장님이 겪는 문제는 대립하는 것처럼 보이지만, 실은 '같은 정보 공백'에서 출발한다.

| 구분 | 겪는 문제 | 근본 배경 |
|---|---|---|
| 이용자(카공족) | 가기 전엔 좌석·콘센트 여부를 알 수 없어 헛걸음 (47% 경험) | 카페 밖에서 확인 가능한 실시간 좌석 정보 채널 부재 |
| 사장님(운영자) | 누가 좌석을 실제로 쓰는지 파악하기 어려워 회전율 관리·갈등 대응이 수동적 | 주문(키오스크)과 좌석 점유 상태가 서로 연동되지 않는 시스템 구조 |
| **공통** | **좌석 상태(비어있음/사용중)가 '보이지 않는' 상태로 방치되어 있다** | **→ 실시간 좌석 데이터화가 곧 해결의 출발점** |

> 자료: 한국리서치(2021) · 진학사 캐치(2025) · 한국농촌경제연구원(2023) 종합 재구성

## 03. 원인분석

### 근본 원인 ① 정보 비대칭 — '가봐야 안다'

카카오맵·네이버지도는 카페의 위치와 리뷰는 보여주지만, 지금 이 순간 좌석과 콘센트가 남아있는지는 알려주지 않는다.

| 기존 지도 앱이 보여주는 정보 | 실제로 필요한 '지금' 정보 |
|---|---|
| 매장 위치·영업시간·전화번호 | 지금 이 시간, 몇 자리가 비어있는가 |
| 별점·방문자 리뷰(과거 시점) | 콘센트 좌석이 남아있는가 |
| 메뉴 사진, 대표 사진 | 혼잡도는 언제쯤 완화되는가 |
| '콘센트 있음' 여부(정적 태그, 사용자 제보 의존) | 예상 대기·이용 가능 시간은 얼마나인가 |

> 자료: 카카오맵·네이버지도 서비스 현황 분석(2026) — 좌석·혼잡도 실시간 정보 항목 부재 확인

### 근본 원인 ② 주문 시스템과 좌석 관리가 분리되어 있다

키오스크·테이블오더는 이미 널리 보급되고 있지만, '결제'만 자동화했을 뿐 '좌석 점유'는 여전히 데이터화되지 않았다.

- 현재 자동화된 영역: **주문 → 결제 → 제조 → 픽업**
- 빠져 있는 연결고리: **좌석 선택 → 점유 상태 기록 → 실시간 외부 공유**

무인주문기(키오스크·테이블오더) 도입률은 2023년 기준 외식업체의 7.8%에 불과하지만, 티오더 20만대·페이히어 7만 가맹점 등 빠르게 확산 중인 인프라 위에 '좌석 선택' 단계만 얹으면 이 공백을 메울 수 있다.

> 자료: 한국농촌경제연구원(2023) · 중소기업신문(2025.3.19, 티오더·페이히어 도입 현황)

### 문제의 뿌리: 두 원인이 만나 하나의 결과를 만든다

- **원인 ①** 정보 비대칭 — 지도·앱에 실시간 좌석 정보 없음
- **원인 ②** 시스템 단절 — 주문(키오스크)과 좌석 점유가 연동 안 됨

**결과**: 이용자는 '가봐야 알고', 사장님은 '지나야 안다' — 좌석이라는 가장 기본적인 자원이 여전히 아날로그로 관리된다.

> 자료: 현황·문제점 데이터 종합 재구성

## 04. 유사콘텐츠분석

### 사례 ① 도서관 좌석 배정 시스템

바코드로 좌석을 '체크인/체크아웃'하는 도서관 열람실 시스템은, 방문 없이도 실시간 좌석 현황을 외부에 공개하는 가장 오래된 성공 사례다.

1. **계정 로그인** — 학생증·회원 계정으로 좌석 배정 시스템에 접속
2. **좌석 선택 & 체크인** — 빈 좌석을 선택하고 바코드를 스캔해 점유 상태로 전환
3. **외부 실시간 확인** — 가지 않아도 웹·앱에서 잔여 좌석 수를 바로 확인 가능
4. **퇴실 시 체크아웃** — 퇴실 시 다시 바코드를 찍어 좌석을 즉시 '이용 가능'으로 전환

**카페 적용 시사점**: 도서관처럼 '좌석 단위'로 체크인·체크아웃을 강제하면, 카페도 방문 전 실시간 잔여 좌석을 외부에 공개할 수 있다. 다만 카페는 결제(음료 주문)와 자연스럽게 결합해야 이용자 저항이 적다.

### 사례 ② 코인노래방 · 무인시설 결제형 공간 선택

코인노래방·스터디카페·무인 독서실은 '공간(방/좌석) 선택 → 결제 → 이용'의 순서를 기계 한 대로 완결한다.

| 코인노래방 방식 | 카페 좌석 키오스크로 응용 |
|---|---|
| 기기 화면에서 빈 방 번호를 직접 선택 | 키오스크 화면에서 빈 좌석 번호를 직접 선택 |
| 이용 시간(요금)을 선택해 결제 | 선택한 좌석 기준으로 음료·메뉴를 주문·결제 |
| 결제 즉시 해당 방이 '사용중'으로 전환 | 결제 즉시 해당 좌석이 '사용중'으로 실시간 전환 |
| 시간 종료 시 자동으로 '이용 가능' 복귀 | 퇴실 태그 또는 자동 시간 만료 시 '이용 가능' 복귀 |

> 자료: 코인노래방·무인 스터디카페 결제 방식 현장 관찰 및 서비스 구조 분석(2026)

### 카페·외식업 무인주문기 시장은 이미 성장 중이다

- **7.8%** — 외식업체 무인주문기 도입률(2023년 기준)
- **20만대+** — 테이블오더 업계 1위 '티오더' 누적 설치 대수
- **7만개** — 핀테크 스타트업 '페이히어' 무인주문 가맹점 수(2025)

**시사점**: 무인주문기 도입률이 7.8%로 아직 낮다는 것은 '초기 확산 단계'라는 뜻이며, 지금이 좌석 선택 기능을 표준 기능으로 끼워 넣을 수 있는 시점이라는 의미다. 신규 도입 매장부터 '좌석형 키오스크'를 표준 옵션으로 제안할 수 있다.

> 자료: 한국농촌경제연구원(2023) · 중소기업신문(2025.3.19)

### 기존 '콘센트 카페 찾기' 콘텐츠의 한계

카카오맵·네이버지도·블로그 등에도 '콘센트 있는 카페' 정보는 존재하지만, 실시간성과 신뢰도에서 구조적 한계가 뚜렷하다.

| 채널 | 제공 정보 | 한계 |
|---|---|---|
| 카카오맵 / 네이버지도 | 위치, 리뷰, '콘센트 있음' 정적 태그 | 실시간 잔여 좌석·혼잡도 정보 없음, 태그는 사용자 제보 의존 |
| 블로그 / SNS 후기 | 방문 당시 좌석·분위기 묘사, 사진 | 작성 시점의 '과거' 정보 — 방문 시점과 무관해 신뢰도 낮음 |
| 카카오맵 AI메이트 로컬 | 대화형으로 맛집·카페 추천 | 추천 로직일 뿐 좌석 재고 데이터 자체가 없어 '지금 갈 수 있는지'는 답하지 못함 |

> 자료: 카카오맵·네이버지도 서비스 분석, 브런치 「카카오맵+AI」(2025.7.17) 재구성

### 종합 비교: 세 가지 사례에서 가져올 것

- **도서관** — 배울 점: 좌석 단위 체크인/아웃 구조 → 외부에서 실시간 잔여석 확인 가능
- **코인노래방** — 배울 점: 결제 = 공간 점유 확정 → 선택 즉시 상태가 자동 전환
- **카페 키오스크** — 배울 점: 이미 보급된 결제 인프라 → 새 기기 없이 기능만 추가 가능

> **결론**: '카페 키오스크 + 좌석 먼저 선택 + 음료 주문 결합'이 세 사례의 장점을 모두 취하는 가장 현실적인 조합이다.

## 05. 해결방안

### 좌석부터 고르는 카페 키오스크

주문 순서를 뒤집는다: **'음료 먼저, 자리는 알아서'** → **'자리 먼저, 그 다음 음료'**

- 기존 순서: 주문 → 결제 → 자리 찾기(운)
- 새로운 순서: **좌석 선택 → 주문 → 결제 = 좌석 확정**

**핵심 원리**: 좌석 선택을 결제 절차 안에 넣으면, '결제 = 좌석 점유 확정'이 되어 별도의 체크인 기기나 직원 개입 없이도 좌석 상태가 자동으로 데이터화된다.

### 서비스 작동 원리: 앱과 키오스크의 연결

이용자는 앱으로 미리 확인하고, 카페는 키오스크로 좌석을 관리한다 — 둘은 하나의 실시간 데이터로 연결된다.

1. **앱에서 확인** — 주변 카페의 실시간 좌석·콘센트 현황을 지도에서 확인
2. **카페 방문** — 여유 좌석이 있는 카페로 이동
3. **키오스크 좌석 선택** — 화면의 좌석 배치도에서 원하는 자리를 직접 선택
4. **음료 주문·결제** — 선택한 좌석 기준으로 메뉴를 고르고 결제
5. **좌석 자동 반영** — 결제 즉시 앱 지도에 '사용중'으로 실시간 반영

> **퇴실 시**: 키오스크 재태그 또는 설정된 이용시간 만료 시 좌석이 자동으로 '이용 가능' 상태로 복귀 — 별도의 직원 개입이 필요 없다.

> 자료: 도서관 좌석 체크인 시스템 및 코인노래방 결제 구조를 응용한 자체 설계(2026)

### 핵심 기능 4가지

이용자의 '헛걸음'과 사장님의 '수동 관리'를 동시에 줄이는 기능으로 설계했다.

- **실시간 좌석 지도** — 주변 카페의 잔여 좌석 수를 색상(초록/빨강)으로 지도에 실시간 표시
- **콘센트 좌석 필터** — 콘센트 인접 좌석만 골라서 검색 · 잔여 콘센트석 수 별도 표기
- **이용시간 알림** — 설정된 시간이 다가오면 이용자에게 사전 알림 — 자연스러운 회전율 관리
- **좌석 예약(시범)** — 혼잡 시간대 특정 좌석을 짧게 사전 예약, 노쇼 방지용 소액 보증금 옵션

## 06. 타겟분석

### 타겟 페르소나: 세 가지 '카공' 유형

카공족은 단일 집단이 아니다 — 목적과 체류 시간에 따라 서로 다른 니즈를 가진다.

| 페르소나 | 프로필 | 핵심 니즈 |
|---|---|---|
| 대학생 · 시험공부형 | 24세, 시험기간에 3~4시간 집중 체류 | 콘센트석 · 조용한 좌석 · 저렴한 가격대 |
| 취준생 · Z세대 구직자 | 26세, 자기소개서·인적성 준비 | 장시간 이용해도 눈치 안 보이는 좌석 |
| 프리랜서 · 1인 사업자 | 32세, 원격근무·미팅 겸용 | 안정적 와이파이 · 회의 가능한 좌석 |

> 자료: 진학사 캐치(2025) Z세대 카공족 실태조사 기반 페르소나 재구성

### 시장 볼륨: 작지 않은, 오히려 커지는 시장

카공족은 특정 세대의 일시적 유행이 아니라, 카페 산업의 소비 구조 변화와 함께 계속 커지는 시장이다.

- 카페 공부 경험률: **2017년 87%** (대학내일20대연구소) → **2025년 71%** (진학사 캐치)

**타겟 시장이 넓은 이유**
- 표본과 세대가 달라도 카페 공부 경험률이 꾸준히 70~90%대 — 조사 시점과 무관하게 구조적으로 높음
- 카공족 특화 브랜드가 이미 수도권 55개 지점으로 확장 — 별도 유료 공간에 지불할 의사가 확인된 시장
- 대형 프랜차이즈가 전용 좌석(포커스존 등)을 늘리는 중 — 서비스가 붙을 '물리적 공간'도 함께 늘어나는 추세

> 자료: 대학내일20대연구소(2017) · 진학사 캐치(2025.8) · 데이터뉴스(2026.3) 종합

## 07. 컨셉

### 서비스 컨셉

> ## "카페, 가기 전에 자리부터 확인하세요"

실시간 좌석·콘센트 지도 × 좌석 선택형 키오스크로, 이용자의 '헛걸음'과 사장님의 '눈치 주기'를 동시에 없애는 서비스

- **이용자에게**: 가지 않고도 아는 카페
- **카페에게**: 말하지 않고도 관리되는 좌석

### 핵심 가치 제안 (Value Proposition)

이용자와 카페 사장님, 양쪽 모두에게 명확한 이득이 있어야 자발적으로 확산된다.

**이용자(카공족)에게**
- 헛걸음 없이 자리 있는 카페로 바로 이동
- 콘센트석을 미리 필터링해 검색 시간 단축
- 눈치 보지 않고 정해진 시간만큼 당당히 이용

**카페 사장님에게**
- 좌석 점유 현황이 자동 데이터화되어 회전율을 정량적으로 파악
- 직접 안내·눈치 주기 없이 이용시간 알림이 자연스럽게 작동
- 매장 노출 확대 — 앱 지도에서 '콘센트 카페'로 신규 고객 유입

### SWOT 분석

좌석 선택형 키오스크 서비스가 가진 내부 역량과 외부 환경을 함께 짚어 전략의 균형을 잡는다.

## 08. 스토리보드

### Scene 1. 앱에서 확인하고 카페로 향하다

- 내 주변 카페 — 카페 A: 빈자리 6 · 콘센트석 2 / 카페 B: 만석 / 카페 C: 빈자리 2 · 콘센트석 0
1. 이용자가 앱을 열어 주변 카페의 실시간 좌석·콘센트 현황을 확인한다.
2. 빈 자리와 콘센트석이 있는 카페 A를 선택하고 도보 경로를 확인한다.
3. '만석'으로 표시된 카페 B는 애초에 후보에서 제외해 헛걸음을 방지한다.

> 이용자 내레이션: "오늘은 카페 A로 가야겠다. 콘센트 자리가 남아있대."

### Scene 2. 키오스크에서 좌석을 고르고 주문하다

- 좌석을 선택하세요 (초록 = 이용 가능 · 빨강 = 사용중 · 콘센트석 강조 표시)
1. 카페 도착 후 키오스크에서 실시간 좌석 배치도를 확인한다.
2. 콘센트가 있는 빈 좌석(초록색, 12번)을 터치해 선택한다.
3. 선택한 좌석 기준으로 음료 메뉴를 고르고 결제를 진행한다.
4. 결제 완료 즉시 12번 좌석이 '사용중'으로 자동 전환된다.

> → 코인노래방의 '방 선택 → 결제' 구조를 카페 좌석에 그대로 적용

### Scene 3. 이용 중 그리고 퇴실

- 이용 알림: "이용시간이 15분 남았어요, 연장하거나 퇴실을 준비해주세요" → "12번 좌석 이용이 종료되었어요, 이용해주셔서 감사합니다"
1. 설정된 이용시간 15분 전, 이용자에게 사전 알림이 전송된다.
2. 더 필요하면 앱·키오스크에서 간단히 연장, 아니면 자연스럽게 정리한다.
3. 퇴실 시 키오스크 재태그(또는 시간 만료)로 좌석이 즉시 '이용 가능'으로 전환된다.
4. 다음 이용자는 앱에서 방금 빈 자리를 실시간으로 확인하고 방문한다.

> → 사장님의 '눈치 주기'를 시스템 알림이 대신해 갈등을 줄인다

## 09. 프로모션 전략

### 초기 확산: 대학가 · 스터디 상권 집중 공략

카공족 밀집도가 가장 높은 상권부터 파일럿을 시작해, 좁고 깊게 검증한 뒤 넓힌다.

1. **1단계: 대학가 파일럿** — 대학내일20대연구소·진학사 캐치 조사에서 확인된 대학가·고시촌 상권 카페 10~20곳과 시범 제휴
2. **2단계: 프랜차이즈 제휴** — 포커스존을 운영 중인 스타벅스·할리스 등과 신규 매장 대상 좌석형 키오스크 공동 테스트
3. **3단계: 전국 확산** — 무인주문기 신규 도입 매장(도입률 7.8%→성장 구간)을 대상으로 표준 옵션으로 제안

> 자료: 진학사 캐치(2025) · 경향신문(2026.4.25) 스타벅스 포커스존 사례 · 한국농촌경제연구원(2023) 종합

### 채널별 확산 전략

이용자에게는 편리함을, 카페 사장님에게는 매출 데이터라는 확실한 유인을 제공한다.

**이용자 대상 (Pull)**
- 대학 커뮤니티·에브리타임 등 캠퍼스 채널 시험기간 집중 광고
- SNS "내 자리 인증" 챌린지로 실사용 후기 확산
- 첫 이용 음료 할인 쿠폰으로 초기 다운로드 유도

**카페 사장님 대상 (Push)**
- 초기 제휴 매장 키오스크 좌석 기능 무상 연동 지원
- 회전율·혼잡시간대 데이터 리포트를 매장 운영에 무료 제공
- 앱 지도 상단 노출 등 매장 홍보 효과를 제휴 인센티브로 제시

## 10. 향후 과제

### 남은 숙제: 기술 · 운영 · 리스크

아이디어를 서비스로 만들기 위해 반드시 짚어야 할 현실적인 제약들.

- **소상공인 도입 비용**: 키오스크 신규 설치·교체 비용 부담 — 기존 포스·테이블오더 API 연동형 저비용 옵션 필요

- **디지털 취약계층 접근성**: 키오스크 사용이 어려운 고령층 등을 위한 직원 대면 대체 경로 유지 필요
