# 크로우 챗봇 — 키워드 응답 테스트 케이스

> **대상**: `크로우_챗봇.html` (배포: https://leegm0430.github.io/seminer/crow_chatbot.html)
> **작성일**: 2026-07-03
> **테스트 방법**: 각 케이스의 입력을 채팅창에 직접 입력하고, 기대 응답과 일치하는지 확인 후 결과 칸에 Pass/Fail 기입
> **공통 판정 기준**: ① 기대 응답 텍스트가 정확히 출력된다 ② 타이핑 표시(···)가 먼저 나온 뒤 응답으로 교체된다 ③ 말버릇("까악"/"~라구")이 포함되어 페르소나가 유지된다
