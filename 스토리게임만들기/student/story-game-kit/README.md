# BRANCH — 스토리 스튜디오

## 시작
ZIP 전체를 압축 해제한 후 editor.html을 Chrome 또는 Edge에서 엽니다.
index.html은 저장된 story-data.js를 실행하는 플레이어입니다.
설치·로그인·서버 없이 사용할 수 있습니다.

## 장면에서 출발하세요
- 장면 지도: 카드를 선택하면 오른쪽에서 제목·이야기·선택지를 편집합니다.
- 선택지의 다음 장면을 바꾸면 지도 연결선이 바뀝니다.
- 카드를 끌어 배치를 바꾸고, 자동 정렬로 되돌릴 수 있습니다.
- 장면 유형을 엔딩으로 바꾸면 결말 장면이 됩니다.
- 장면의 이미지는 끌어놓거나 클릭해서 데이터에 포함할 수 있습니다. PNG/JPG/WebP/GIF, 4MB 이하.
- 이미지 없이도 기본 배경으로 플레이됩니다.

## 나만의 규칙
아이템의 최초 획득 효과, 스킬의 획득 가능한 캐릭터, 캐릭터별 시작값을 설정합니다.
스탯 연결에서 범위와 계산식을 만듭니다. 계산 대상 = 원본 × 배율 + 상수 + 더할 스탯.
선택지의 조건 · 효과 · 획득에서 복합 AND 조건, 수치 변화, 랜덤 획득을 설정합니다.
프로젝트에서 자동 엔딩 규칙을 추가하고 순서를 바꿀 수 있습니다.

## 플레이와 실험
상단 플레이는 현재 편집 중인 게임을 바로 실행합니다.
테스트 룸은 장면·캐릭터·스탯·아이템·스킬·난수 시드를 직접 지정하는 실험 공간입니다.
테스트 룸에만 변화 로그가 표시됩니다. 실제 플레이어에는 제작·검사 메뉴가 없습니다.
직접 지정한 보유 아이템은 효과를 다시 더하지 않습니다. 획득 효과는 플레이에서 확인하세요.
같은 데이터·상태·시드·행동 순서면 랜덤 결과도 같습니다.

## 저장
1. 저장 → 제작 데이터 저장: story-data.js를 내려받아 다음에 불러와 편집합니다.
2. 저장 → 플레이 HTML 저장: my-story.html 한 파일로 플레이합니다. 끌어놓은 이미지는 함께 포함됩니다.
3. 키트의 index.html에 반영하려면 내려받은 story-data.js로 기존 파일을 교체합니다.
파일명으로 연결한 외부 이미지/영상은 images/videos 폴더도 함께 보관해야 합니다.
브라우저 임시 저장은 보조 기능입니다. 작업을 마치면 파일로 저장하세요.
게임 진행 저장 코드는 제작 데이터와 별개이며, 같은 게임 데이터에서 이어하기에 사용합니다.

## AI 데이터
AI 서비스에서 받은 아이템 JSON을 복사해 검사하고 반영할 수 있습니다.
형식·중복·수치 범위는 자동 검사하며, 설명과 효과의 의미는 직접 확인합니다.
AI 서비스 연결이나 API 키 입력은 필요 없습니다.

## 규칙의 처리 순서
행동 전 조건 → 일반/연동 효과 → 최초 아이템 효과 → 범위 보정과 계산 스탯 갱신 → 스킬 획득 조건 → 자동 엔딩.
연동 효과는 행동 전 원본값을 사용합니다. 자동 엔딩은 위쪽 규칙이 우선합니다.
아이템은 첫 획득 시 1회 효과이며, 장착·소모품 사용 기능은 없습니다.
현재 템플릿은 분기형 이야기와 선택형 턴제 전투입니다. 실시간 슈팅은 지원하지 않습니다.

## 기존 파일
기존 story-data.js를 불러올 수 있습니다. 데이터 형식 오류가 있으면 먼저 수정해야 합니다.
기존 브라우저 임시 작업도 첫 실행 시 읽을 수 있습니다. 원본은 파일로 별도 보관하세요.
이미 만든 잘못된 순환 계산이나 없는 장면 참조는 프로젝트 → 데이터 검사에서 확인하세요.

플레이 화면 개선: 본문과 선택지를 위쪽에 배치했습니다. 공격·스탯 변화·새 아이템과 스킬 획득은 중앙 알림으로 표시됩니다. 알림은 자동으로 닫히며 계속하기로 즉시 닫을 수 있습니다. 아이템 아이콘이 있으면 함께 표시합니다. 전투 예제는 선택지 기반 이야기이며 독립적인 턴제 전투 시스템은 아닙니다.

AI 제작·테스트: 장르·배경·분위기·목표로 개인화 프롬프트를 만들고, AI JSON을 검사해 현재 게임에 적용할 수 있습니다. ID와 장면 연결은 보존됩니다. 현재 게임으로 AI 테스트 JSON을 만든 뒤 실제 규칙 엔진에서 예상값과 비교할 수 있습니다. 형식 통과는 의미가 옳다는 보장이 아니므로 선택 문구·아이템 설명·예상 결과를 직접 확인하세요.

파일 불러오기 구분: 상단 프로젝트 불러오기는 story-data.js 또는 전체 프로젝트 JSON용입니다. AI 개인화 팩은 AI 제작·테스트 B의 개인화 JSON 파일 불러오기, AI 테스트 팩은 C의 테스트 JSON 불러오기를 사용하세요.

AI 제작·테스트 파일 흐름: 개인화 JSON은 B에서 현재 게임을 바꿉니다. 테스트 JSON은 C에서 예상과 실제를 비교할 뿐 게임을 바꾸지 않습니다. 아이템 JSON은 D에서 목록에 등록한 뒤 장면 지도의 선택지에서 획득 아이템으로 연결해야 플레이에 등장합니다. 현재 게임 전체는 상단 저장의 제작 데이터 저장으로 보관합니다.
