# [BUG-004] [카메라] 차량 속도가 낮은 값으로 연속 설정되면 카메라가 차량을 앞질러 추적에 실패함

| 항목 | 내용 |
|---|---|
| 버그 ID | BUG-004 |
| 발견일 | 2024-05-24 |
| 보고자 | 이경민 |

| 모듈/기능 | 카메라 / 추적 로직 |
| 우선순위 | P2 |
| 심각도 | Major |
| 재현율 | 가끔 (10~50%) |
| 상태 | 신규 |

## 발생 환경
- 빌드 버전: Unity 2022.3.10f1
- 플랫폼/기기: PC
- OS/브라우저: Windows 10

## 상세 설명
자동차의 속도가 18~25 범위에서 무작위로 결정될 때, 차량 속도가 연속적으로 18~20 등 낮은 값으로 설정되면 차량을 추적하는 카메라의 이동 속도가 더 빨라 카메라가 차량을 앞질러 가 버리는 현상이 발생함.
카메라 이동 속도가 차량 속도와 무관한 고정값으로 설정되어 있는 것으로 추정되며, 이로 인해 플레이어는 레이싱 장면을 제대로 볼 수 없음.

## 사전 조건
레이싱 게임을 실행할 수 있는 상태여야 함

## 재현 스텝
1. 레이싱 게임을 시작한다
2. 자동차의 속도가 연속적으로 낮은 값(18~20 범위)으로 설정될 때까지 진행한다
3. 차량보다 카메라가 앞질러 가는지 확인한다

## 기대 결과
카메라의 이동 속도는 차량의 실제 속도에 비례하여 설정되거나, 차량을 항상 프레임 중앙·특정 위치에 안정적으로 담을 수 있도록 지연 보정 처리가 되어야 한다

## 실제 결과
차량 속도가 낮은 값으로 연속 설정된 구간에서 카메라가 차량보다 앞서 이동하여, 차량이 화면 뒤로 벗어남.

3. 몬스터의 애니메이션은 이동 또는 대기 상태에 따라 정상적으로 재생되어야 한다

1. 몬스터가 인식 범위 안의 플레이어를 추적하지 못함
2. 추적 도중 몬스터의 이동과 애니메이션이 함께 멈춤
3. 벽(나무 오브젝트)에 접촉한 몬스터가 경계에 붙어 좌우로 떨림

1. 메이플플래닛 월드에 플레임위자드 LV.42 캐릭터(닉네임 menhoji)로 접속한다
2. 아이템 인벤토리에서 '노란색 우산'의 요구 조건(REQ LEV 40 / REQ STR·DEX·INT·LUK·POP 모두 0)을 확인한다
3. 캐릭터 스탯 창에서 레벨과 스탯이 요구 조건을 충족하는지 확인한다
4. '노란색 우산'을 착용한다
5. 요구 스탯이 모두 0인 시그너스 직업군 튜토리얼 의상으로도 동일하게 착용을 시도한다

## 기대 결과
캐릭터의 레벨과 스탯이 장비의 요구 조건을 충족하면 해당 장비가 정상적으로 착용되어야 한다

## 실제 결과
· 캐릭터: 플레임위자드 LV.42 / STR 4 · DEX 4 · INT 218 · LUK 4
· 아이템: 노란색 우산(에픽) / REQ LEV 40 · REQ STR 0 · REQ DEX 0 · REQ INT 0 · REQ LUK 0 · REQ POP 0
요구 조건을 모두 충족했음에도 착용 시 미충족으로 표시되며 장착되지 않음. 요구 스탯이 0인 시그너스 튜토리얼 의상도 동일함.
