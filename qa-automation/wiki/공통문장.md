# 공통 문장 사전

TC 문장을 실행 동작으로 바꾸는 표입니다. `tools/wiki_run.py`가 읽습니다. 모든 게임에 함께 쓰입니다.

- 줄을 더하면 다음 실행부터 그 문장을 읽습니다. 위에서부터 차례로 맞춰 봅니다.
- 문장에 쓰는 자리 이름: `{버튼}` `{문구}` `{N}` `{값}`
- 동작: `클릭 {버튼}` · `클릭 {버튼} {N}번` · `입력 {버튼} {값}` · `키 {값}` · `대기 {N}초` · `새로고침` · `없음`
- 판정: `보임 {문구}` · `안보임 {문구}` · `비활성 {버튼}` · `활성 {버튼}`
- 따옴표(" “ ” ')는 모두 같은 것으로 읽고, 문장 끝의 마침표는 무시합니다.

| 종류 | 문장 | 동작 |
|---|---|---|

| 조작 | - | 없음 |

| 조작 | [{버튼}] {N}번 클릭 | 클릭 {버튼} {N}번 |

| 조작 | [{버튼}] 클릭 | 클릭 {버튼} |
| 조작 | [{버튼}] 버튼 누름 | 클릭 {버튼} |
| 조작 | [{버튼}] 누름 | 클릭 {버튼} |
| 조작 | [{버튼}] 선택 | 클릭 {버튼} |
| 조작 | [{버튼}] | 클릭 {버튼} |
| 조작 | [{버튼}]에 "{값}" 입력 | 입력 {버튼} {값} |
| 조작 | {N}초 기다리기 | 대기 {N}초 |

| 조작 | {버튼} 클릭 | 클릭 {버튼} |
| 조작 | {값} 확인 | 없음 |
| 판정 | "{문구}" 문구가 표시 됨 | 보임 {문구} |
