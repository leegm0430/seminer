## 조작 묶음

여러 조작이나 사전 조건을 한 문장으로 등록합니다. 조작은 ` / `로 나눕니다.

| 문장 | 조작 |
|---|---|
| 저장된 진행이 없는 첫 화면 | 없음 |
| 첫 화면 | 없음 |
| 1단계, 아무것도 고르지 않은 상태 | [1단계] 클릭 |
| 2단계, 속성 불꽃·이름 "화산"을 정한 상태 | [1단계] 클릭 / 🔥 불꽃 클릭 / 이름 "화산" 입력 / [다음 단계로] 클릭 |
| studio.html 열기 | 없음 |
