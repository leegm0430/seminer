AI 활용 게임 QA 자동화

이경민 · 2026-11-01 ~ 11-02 · 비용 0원 (오픈소스 + Jira 무료 플랜, 유료 앱·AI API 호출 없음)

무엇을 만들었나

기획서나 기존 TC를 넣으면 TC 작성 → 규칙 점검 → 게임 자동 테스트 → 결과 리포트·TC 엑셀 → Jira 이슈 등록까지 이어지는 흐름입니다.

기획서 PDF·이미지·기존 TC 엑셀→ TC 작성 (Claude Code + 직접 만든 TC 작성 규칙)→ 규칙 점검→ Playwright 자동 테스트→ 리포트·TC 엑셀→ Jira TC·버그 이슈

게임 파일이 없으면 자동 테스트는 건너뛰고, TC 검토 의견·기획서 확인 필요 사항·추가 제안을 정리하고 끝납니다.

직접 써 보기 (설치 없음)

TC 엑셀이나 기획서 PDF를 넣으면 제가 정한 TC 작성 규칙으로 점검하고, 기획서에는 있는데 TC에 없는 문구·버튼·수치를 찾아 줍니다. 파일은 브라우저 안에서만 읽고 어디에도 올라가지 않습니다.

AI와 제 역할 나누기

제가 정한 것무료 도구만 쓰기, TC 작성 규칙(공개 자료·제가 쓴 TC 2종을 참고해 정리), 테스트할 게임과 기획서, AI 결과 검토·채택
AI(Claude Code)가 한 것규칙대로 TC 초안 작성, 테스트 코드·도구 코드 작성, 실행 결과 정리
배운 점처음엔 AI가 확인 항목을 한 줄에 묶어 TC가 55건뿐이었음 → 규칙에 "화면 요소·문구·값마다 TC" 같은 커버리지 규칙을 넣자 338건으로 늘고 실제 결함 1건을 찾음. AI 결과 품질은 규칙을 얼마나 구체적으로 주느냐에 달려 있었습니다.

한계

  • TC 작성 단계는 제 PC의 Claude Code에서 돌립니다. 나머지(점검·테스트·리포트·Jira)는 AI 없이 돌아갑니다.
  • 자동 테스트는 웹(html) 게임 대상입니다. 유니티 빌드 게임은 아직 못 합니다.
  • 기획서 대비 빠진 항목 찾기는 글자 비교라서 후보일 뿐이고 사람이 확인해야 합니다.
