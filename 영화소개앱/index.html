⚙️ TMDB API 키가 설정되지 않았습니다

REELVAULT는 별도 서버 없이 브라우저에서 TMDB API로 바로 요청합니다. 사이트 운영자는 아래 절차로 한 번만 설정하면 됩니다.

  1. TMDB 설정 페이지에서 이 포트폴리오/데모용 API 키를 새로 발급 (메인 계정 키와 분리)
  2. 발급받은 키를 index.html 상단의 TMDB_API_KEY 상수에 입력
  3. 저장 후 파일을 다시 열거나 업로드 — 방문자는 이 화면을 보지 않고 바로 서비스를 이용합니다

데모 전용 키이므로 유출되어도 TMDB에서 재발급 후 교체만 하면 되고, 다른 서비스에는 영향이 없습니다.
