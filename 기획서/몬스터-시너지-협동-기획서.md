## 1. 몬스터 로스터 15종 — 챕터별 풀

원작 도감의 핵심 행동 문법을 오마주: **추적 / 사격 / 도약 / 돌진 / 사망 시 특수효과(소환·분열·자폭) / 무적 사이클 / 부활**.
챕터가 깊어질수록 새 행동이 추가되고, 체력은 층 배율(+15%/층)로 스케일.

| 🧟 게이퍼 | Gaper | 14 | 직선 추적 (기본 근접) |
| 🦟 푸터 | Pooter | 9 | 부유하며 거리 유지, 주기적으로 단발 사격 |
| 🩸 클로티 | Clotty | 12 | 무작위 방향 배회 + 주기적 **+자 4방향** 탄 |

## 3. 명시적 시너지 콤보 6종

기본 원칙(모든 플래그 곱연산 중첩)에 더해, **특정 아이템 2종을 모두 보유하면 보너스 효과**가 발동한다.
발견 시 토스트로 "💥 시너지 발견!"을 알리고 사이드 패널에 상시 표시 — 조합 수집욕 자극 장치.

| 시너지 | 조합 | 효과 |
|---|---|---|
| 사방팔방 | 👓 겹눈 안경 + 👁️ 제3의 눈 | 동시 발수 +1, 공격 ×1.1 |
| 맹독 오라 | 🕷️ 거미 독샘 + 🧪 산성 침 | 플레이어 주변 95px 적에게 지속 독 피해 |
| 빙하 해일 | ❄️ 얼음 조각 + 🌊 파도 눈물 | 감속 지속 2배, 넉백 거리 2배 |
| 안전 신관 | 💥 화약 눈물 + 🎈 고무 눈물 | 폭발 눈물 자해 면역 + 폭발 반경 확대 |
| 스마트 미사일 | 🧲 자석 눈물 + 🪃 부메랑 눈물 | 유도 조향 3배 + 사거리 +80 |
| 농축 점액 | 🔱 외눈박이 대왕눈물 + 🐌 달팽이 점액 | 공격 ×1.5 추가 보정 (상쇄 조합 구제) |

> 설계 의도: 자동 곱연산 시너지(암시적)와 별개로, "이 둘을 모으면 뭔가 특별한 게 된다"는 **명시적 목표**를 소수 심어 빌드 방향성을 만든다. 원작의 Brimstone+Tammy's Head 같은 전용 시너지의 축소판.

## 4. 협동 아기 (Co-op Baby) — 로컬 2P

원작 리버스의 협동 베이비 시스템 오마주: **2P는 언제든 난입 가능, 대가는 1P의 하트 용기**.

| 규칙 | 내용 |
|---|---|
| 참가 | `B` 키. **1P의 하트 용기 1개를 희생** (최대 체력 2칸 미만이면 참가 불가) |
| 2P 조작 | `TFGH` 이동 + `IJKL` 발사 |
| 능력치 | 1P 스탯의 70% 공격력, 발사 딜레이 +6프레임, 사거리 80% — **눈물 속성(유도·관통 등)은 전부 공유** |
| 체력 | 하트 2개(4칸). 층 이동 시 1칸 자동 회복 |
| 사망 | 2P만 퇴장. `B` 키로 재참가 가능 (다시 용기 1개 희생) |
| 게임 오버 | 1P 사망 시에만 발생 |
| 이동 제약 | 방 전환은 1P 기준, 2P는 함께 순간이동 |

> 설계 의도: 참가 비용(용기 희생)이 있어 "공짜 화력"이 아니라 **리스크 교환**이 된다. 원작 규칙의 핵심 재미 포인트.
