## 1. 문서 개요

### 1.1 문서 목적
본 문서는 챌린저스 월드의 핵심 진행 시스템인 '챌린저스 티어 시스템'을 기획자 관점에서 재구성한 역기획서다. 시스템의 목적 정의, 동작 규칙, 데이터 테이블, UI 구성, 예외 처리를 개발·QA가 참조 가능한 수준으로 명세하는 것을 목표로 한다.

### 1.2 시스템 범위
- **포함**: 포인트 획득 규칙(레벨/보스 미션), 티어 산정·승급 규칙, 관문 보스 연동, 슈퍼챌린저 랭킹, 티어 연동 효과(패시브 스킬·의문의 결계 해금·보상), 반지 선택권 분기, 관련 UI/UX, 예외 처리
- **제외**: 주간 미션·시즌 미션(코인 전용 — 티어에 미관여), 챌린저스 코인샵, 챌린저스 패스, 아이템 버닝(별도 문서에서 다룸)

### 1.3 용어 정의
| 용어 | 정의 |
|---|---|
| 챌린저스 포인트 | 티어 산정의 기준이 되는 누적 점수. 메이플ID(월드 단위) 귀속 |
| 티어 | 포인트 및 관문 조건으로 결정되는 10단계 등급 |
| 관문 보스 | 포인트 외에 격파가 승급 조건으로 요구되는 시즌 보스(메이린) |
| 챌린저스 패시브 | 티어에 연동되어 강화되는 월드 전용 버프 스킬 |
| 랭킹 정원 | 슈퍼챌린저 티어에 배정된 월드별 선착순 정원 |

## 2. 시스템 개요

### 2.1 시스템 정의
챌린저스 티어 시스템은 시즌 기간 동안 캐릭터 성장(레벨)과 보스 격파 성과를 포인트로 수치화하고, 누적 포인트와 관문 보스 격파 여부에 따라 10단계 티어를 부여하는 **월드 단위 진행도·경쟁 시스템**이다. 티어는 (1) 월드 전용 패시브 버프의 강화 단계, (2) 의문의 결계의 해금 단계, (3) 티어별 보상 지급, (4) 훈장·랭킹을 통한 명예 표시의 네 가지 하위 시스템과 연동된다.

### 2.2 기획 목표
1. **성장의 수치화·목표화**: "다음에 뭘 해야 하는가"를 포인트라는 단일 지표로 환원해 시즌 전 기간의 목표를 상시 제공한다.
2. **경쟁과 육성의 결합**: 티어 상승이 곧 전투력(패시브·결계) 상승이 되도록 하여, 경쟁 참여가 육성 효율로 직결되게 한다.
3. **시간 투자와 실력 증명의 이원 검증**: 상위 티어에 포인트(시간)와 관문 보스 격파(실력)를 동시에 요구해 랭킹의 권위를 확보한다.
4. **본 서버 환류**: 상위 티어 보상을 정착 예정 월드에서 수령 가능하게 하여, 시즌 성취를 장기 리텐션 자산으로 전환한다.

### 2.3 시스템 구성도
```
[레벨 미션] ──┐
              ├─> [챌린저스 포인트 누적] ─> [티어 판정] ─┬─> [챌린저스 패시브 강화]
[보스 미션] ──┘         (메이플ID 귀속)        │          ├─> [의문의 결계 해금 단계]
                                    [관문 보스 격파 여부]──┤          ├─> [티어별 보상 지급]
                                    [슈퍼챌린저 랭킹 정원]─┘          └─> [훈장/랭킹 표시]
```

### 2.4 귀속 단위 정의
| 항목 | 귀속 단위 |
|---|---|
| 포인트/티어 | 메이플ID × 챌린저스 월드 (월드 내 전 캐릭터 공유) |
| 미션 달성 판정 | 월드 내 임의 캐릭터로 달성 가능, 보상은 ID당 1회 |
| 패시브 적용 | 월드 내 전 캐릭터 |
| 티어 보상 수령 | 티어 구간에 따라 수령 가능 월드 상이 (3.4 참조) |

## 3. 시스템 상세 명세

### 3.1 포인트 획득 규칙

#### 3.1.1 공통 규칙
- R-01. 포인트는 레벨 미션과 보스 미션에서만 획득된다. (주간/시즌 미션은 코인만 지급) **[정정]** 레벨·보스 미션은 포인트와 챌린저스 코인을 **동시 지급**한다. 코인 단독 지급(주간/시즌 미션)과 포인트+코인 동시 지급(레벨/보스 미션)이 공존하는 구조다.
- R-02. 각 미션의 포인트는 메이플ID당 1회만 지급된다.
- R-03. 시즌 내 획득 가능한 최대 포인트는 138,000점이다. (레벨 36,700 + 보스 101,300)
- R-04. 포인트는 차감·소멸되지 않는다. 티어는 하락하지 않는다.

#### 3.1.2 레벨 미션
| 구간 | 단위 포인트 | 구간 합계 | 단위 코인 (확인분) |
|---|---|---|---|
| 260레벨 달성 | 3,000 | 3,000 | 3,000 |
| 261~269 (레벨당) | 300 | 2,700 | 300 |
| 270~274 (레벨당) | 700 | 3,500 | ※미확인 |
| 275~279 (레벨당) | 1,000 | 5,000 | ※미확인 |
| 280~284 (레벨당) | 1,500 | 7,500 | 1,200 |
| 285~289 (레벨당) | 2,000 | 10,000 | 1,500 |
| 290레벨 달성 | 5,000 | 5,000 | ※미확인 |
| **누계** | | **36,700** | |

- 코인 지급량은 캡처로 확인된 구간(260, 261~264, 281~284, 285)만 확정 표기했으며, 나머지 구간은 ※미확인으로 남겨둔다. 포인트 대비 코인 비율이 구간마다 다르므로(260: 100%, 280대: 약 80%) 단순 비례식으로 추정하지 않는다.

- R-05. 레벨 미션은 달성 즉시 자동 완료 처리된다. 하위 레벨 미션은 상위 레벨 달성 시 일괄 완료된다. ※추정: 레벨 다운(사망 경험치 손실)에 의한 재달성 중복 지급은 발생하지 않는다.

#### 3.1.3 보스 미션
- R-06. 판정 조건: **파티원 1인 상태로 해당 보스의 마지막 페이즈를 처치**한 시점에 완료된다.
- R-07. **연습 모드 클리어도 인정**된다. (주간 격파 횟수 제한·결정석 경제와 티어 경쟁을 분리하기 위한 사양)
- R-08. 동일 보스의 상위 난이도 격파 시, 하위 난이도 미션이 일괄 완료 처리되고 보상이 누적 지급된다.
- R-09. 시즌 보스(메이린)는 주 1회 클리어 제한과 별개로, 미션 완료 판정은 최초 1회 격파 시점에 발생한다.

| 구간 | 대표 보스 (난이도) | 포인트 | 비고 |
|---|---|---|---|
| 하위 | 카오스 자쿰 ~ 카오스 파풀라투스 | 100~300 | |
| 중위 | 노멀 스우/데미안 400, 이지~노멀 루시드/윌 500~1,000, 노멀 더스크/듄켈 1,000 | 400~1,000 | |
| 상위 | 하드 스우/데미안 1,500~, 하드 루시드 2,000, 카오스 가엔슬/더스크·하드 윌 2,500, 노멀 진 힐라 2,000, 하드 진 힐라/듄켈 3,000 | 1,500~3,000 | |
| 최상위 | 하드 검은 마법사 6,000, 노멀 세렌 6,000, 하드 세렌·이지 칼로스·이지 대적자 7,000, 노멀 칼로스·노멀 대적자·이지 카링 9,000 | 6,000~9,000 | 하드 검마 이상 상급 코인 병행 지급 |
| 시즌 보스 | 메이린 노멀 5,000 / 하드 9,000 | 5,000~9,000 | 관문 보스 겸용 |
| **누계** | | **101,300** | |

| 티어 | 요구 포인트 | 추가 조건 |
|---|---|---|
| 비기너 | 0 (기본 상태) | - |
| 브론즈 | 5,000 | - |
| 실버 | 10,000 | - |
| 골드 | 15,000 | - |
| 플래티넘 | 20,000 | - |
| 에메랄드 | 30,000 | - |

#### 3.2.2 승급 판정 규칙
- R-10. 승급 판정은 포인트 변동 또는 관문 보스 격파 이벤트 발생 시점마다 수행된다.
- R-11. 포인트와 관문 조건이 모두 충족된 순간 즉시 승급하며, 충족 순서는 무관하다. (예: 메이린 노멀을 먼저 격파해 두면 70,000점 도달 시점에 마스터로 즉시 승급)
- R-12. 다단계 조건이 동시에 충족되면 최고 티어로 일괄 승급하며, 경유한 하위 티어 보상은 모두 수령 가능 상태가 된다.

#### 3.2.3 슈퍼챌린저 랭킹 규칙
- R-13. 랭킹 정원: 챌린저스·챌린저스2·챌린저스3 각 999명, 챌린저스4는 50명.
- R-14. 순위는 슈퍼챌린저 조건(90,000점 + 하드 메이린 격파) **최종 충족 시각의 선착순**으로 부여된다.
- R-15. 정원 초과 이후 조건을 충족한 유저는 챌린저 티어로 유지된다. (랭킹 이탈에 의한 결원 승계는 없음 ※추정)
- R-16. 순위 1~10위에게는 전용 훈장(1st~10th)이 부여된다. 챌린저 훈장에는 달성 순위가 각인된다.

### 3.3 티어 연동 효과 — 패시브 스킬
- R-17. 패시브 스킬 '챌린저스 비기너'는 월드 내 전 캐릭터에게 상시 적용되며, 티어 승급 시 즉시 갱신된다.
- R-18. 다이아몬드 도달 시 전 효과가 개방되고 스킬명이 '챌린저스'로 고정된다. (사파이어~슈퍼챌린저 동일 효과)
- R-19. UI에 **다음 티어 달성 시의 버프 상승치 미리보기**를 제공한다. (시즌4 신규 사양)

| 경험치 획득량 | +50% | ← | ← | ← | ← | ← |

### 3.4 티어 연동 효과 — 결계 해금·보상 지급

#### 3.4.1 의문의 결계 해금 단계
| 단계 | 결계 등급 | 해제 가능 티어 |
|---|---|---|
| 1단계 | 초소형 | 골드 미만 |
| 2단계 | 소형 | 골드 이상 |
| 3단계 | 중형 | 에메랄드 이상 |
| 4단계 | 대형 | 사파이어 이상 |
| 5단계 | 초대형 | 다이아몬드 이상 (최종 단계) |

#### 3.4.2 보상 지급 규칙
- R-20. 티어 보상은 승급 시 자동 지급되지 않고, 보상 UI에서 **수령 월드를 지정해 수동 수령**한다.
- R-21. 수령 가능 월드: 브론즈~플래티넘 보상은 현재 챌린저스 월드 전용. 에메랄드 이상 보상은 리프 가능 월드군(챌1~3 → 에오스/핼리오스 제외 일반 월드, 챌4 → 에오스/핼리오스) 중 선택 수령 가능.
- R-22. 보상 아이템의 사용 기한은 2026.09.30이며, 솔 에르다 조각·티어 모자·페어리 하트는 영구 아이템으로 지급된다.
- R-23. 반지 선택권 분기: 브론즈(3레벨)·실버(4레벨) 반지 선택권은 상호 배타 상태를 가진다.

## 5. UI/UX 명세

> 본 장은 실제 인게임 캡처 6종을 기준으로 재작성되었다. 이전 버전(v1.0)에 기술되었던 '랭킹 탭', '월드 선택 드롭다운', '다음 등급 버프 미리보기 버튼', '티어 승급 연출'은 캡처에서 확인되지 않아 **모두 삭제**하고, 실제 확인된 구조로 대체했다.

### 5.1 진입점
- 이벤트 리스트 또는 화면 우측 이벤트 아이콘을 통해 '챌린저스 월드' 전용 창을 연다. 창 우상단에 시즌 기간이 상시 표기된다 (예: `2026년 06월 18일(목) ~ 2026년 09월 16일(수) 오후 11시 59분까지`).
- 창 우상단에는 창과 별개로 **'생성 보상 받기'** 툴팁이 붙은 선물 아이콘이 노출될 수 있다. 이는 챌린저스 월드 캐릭터 생성 혜택(2.3절, 본 티어 시스템 범위 밖) 수령 진입점이며, 티어 시스템과는 무관하다.
- 창 상단에는 '?' 아이콘의 **확률정보** 버튼이 있다. 클릭 시 결계의 핵 등장 확률 등 확률 고지 팝업이 뜬다 (별도 문서 「콘텐츠 분석서」 3.5절 참조 대상).

### 5.2 공통 구조 — 창 레이아웃
전 탭 공통으로 창은 **좌측 고정 패널 + 우측 탭 콘텐츠 영역**의 2분할 구조를 가진다. 탭은 **보상 / 보스·레벨미션 / 주간·시즌미션** 3개뿐이며, 별도의 '랭킹' 탭은 존재하지 않는다.

#### 5.2.1 좌측 패널 — 상태 머신
좌측 패널은 오직 두 상태만 가지며, 상태 전환은 애니메이션 없이 즉시 갱신된다.

| 상태 | 표시 요소 |
|---|---|
| **S0. 티어 미달성** (비기너, 5,000P 미만) | 자물쇠 아이콘(잠금) + "티어 달성 전" 텍스트 + 누적 포인트 숫자 (예: 0, 4450) |
| **S1. 티어 달성** (브론즈 이상) | 해당 티어 엠블럼 그래픽(반짝임 효과) + 티어명 텍스트(예: "DIAMOND") + 누적 포인트 숫자 (예: 69000) |

- 상태 전환 조건: R-11(포인트+관문 동시 충족 시 즉시 승급)의 결과가 발생하는 즉시 S0→S1 또는 S1의 엠블럼/명칭만 다음 티어로 교체된다. **별도의 연출·이펙트·안내 팝업은 없다.**
- 패널 하단 고정 요소 (상태와 무관하게 항상 노출):
  - 챌린저스 코인 보유량 (예: 7,600개 / 0개 / 560개)
  - 상급 챌린저스 코인 보유량 (예: 0개 / 10개)
  - **[상점 열기]** 버튼 — 챌린저스 코인샵 진입 (본 문서 범위 밖)

### 5.3 화면 A — 보상 탭

#### 5.3.1 버프 미리보기 카드 (NOW / NEXT)
R-19('다음 등급 버프 미리보기')는 별도 팝업이 아니라 **탭 상단의 인라인 카드 2장**으로 구현되어 있다.

| 카드 | 상태별 표시 |
|---|---|
| NOW 카드 | 라벨 "NOW" + 현재 적용 중인 등급명("챌린저스 OO 버프") + 전체 효과치 텍스트 목록 |
| NEXT 카드 | 라벨 "NEXT" + 다음 등급명 + **변경되는 효과만** 발췌 표시 (예: "일반 몬스터 공격 시 데미지 100% → 150%로 증가") |

- 다이아몬드(전 효과 개방) 도달 이후에는 NEXT 카드가 사라지고 그 자리에 **"버프 효과 모두 획득!"** 안내 카드로 대체된다.
- NOW 카드의 전체 효과 목록은 3.3절 패시브 표와 동일한 항목을 티어에 맞춰 전량 나열한다(경험치·공마·몬데미·보데미·방무·버지·크뎀·스탠스·올스탯·HP/MP·소환수·쿨감·길드 기여도·해방룬 등).

#### 5.3.2 티어별 보상 리스트
우측 영역에 티어 행이 세로로 나열된다 (브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 사파이어 → 다이아몬드 → 마스터 → **챌린저/슈퍼챌린저 통합 행**). 에메랄드~마스터 행은 스크롤 시 노출된다.

각 행의 구성:
- 티어 엠블럼 아이콘 + 티어명(영문 대문자, 예: BRONZE) + 요구 포인트(예: ₩5000)
- 보상 아이템 아이콘 슬롯 여러 개, 각 아이콘에 **수량 배지**가 오버레이된다 (예: x100, x3, x300, x5). 수량 배지가 없는 아이콘은 단일 수령 아이템이다.
- 슬롯별 상태:
  - **미도달**: 아이콘 흐림 처리, 버튼 없음
  - **도달 + 미수령**: 슬롯에 **[받기]** 버튼 활성화
  - **전량 수령 완료**: 아이콘 위에 **체크마크(✓) 오버레이**, 버튼 사라짐
- **챌린저/슈퍼챌린저 통합 행** (90,000점 공통 컷): 별도의 랭킹 탭 대신 이 행 안에 **"현재 챌린저 달성 인원"** 카운터가 실시간 숫자로 표시된다 (예: 0명, 8,359명). 슈퍼챌린저 개인 순위(1~999등/1~50등)를 확인하는 별도 리더보드 UI는 본 캡처에서 확인되지 않았다 (※ 존재 여부 미확인 — 3.2.3절 랭킹 규칙 자체는 서버 로직으로 별도 존재).

#### 5.3.3 하단 고정 안내 (전 티어 공통 표기)
탭 하단에 3줄 고정 텍스트로 상위 티어 달성 조건이 항상 노출된다:
```
챌린저스 1~3 월드 티어 달성 조건
· 마스터: 70,000점 달성 & 메이린(노멀) 격파
· 챌린저: 90,000점 달성 & 메이린(하드) 격파 & 1,000등부터
· 슈퍼챌린저: 90,000점 달성 & 메이린(하드) 격파 & 999등까지
```

### 5.4 화면 B — 보스·레벨미션 탭

#### 5.4.1 보스 미션 그리드
- 보스 초상화 아이콘이 그리드로 배열되며, 상단에 고정 라벨 **"클리어 난이도 이하 자동 완료"**가 R-08(상위 난이도 격파 시 하위 일괄 완료)을 사용자에게 안내한다.
- 그리드와 별도로 **시즌 보스(메이린) 카드**가 우측에 독립 배치되며, 하단에 "SEASON BOSS" 배지가 붙는다.
- **격파 판정 표시 방식**: 보스를 격파(또는 R-07의 연습 모드 클리어)하면 해당 보스 초상화 아이콘 위에 **체크마크(✓)가 직접 오버레이**된다. 별도의 토스트 알림이나 팝업은 확인되지 않았다 (이전 버전 N-01의 '토스트 알림' 기술은 ※미확인 상태로 하향 조정).
- 아이콘을 클릭하면 우측 상세 패널에 해당 미션 정보가 표시된다. 미클릭 상태의 기본 문구는 "미션을 클릭하면 미션 정보를 확인할 수 있습니다." (뒤로가기 화살표 아이콘 동반).

#### 5.4.2 레벨 미션 테이블
컬럼: `미션 리스트 | 챌린저스 포인트 | 챌린저스 코인`. 행 예시: "260레벨 달성하기 / ₩3,000 / 3,000코인", "285레벨 달성하기 / ₩2,000 / 1,500코인". 달성 시 별도 팝업 없이 포인트·코인이 즉시 가산되고(R-05), 행 자체의 완료 표시 방식은 본 캡처에서 명확히 확인되지 않아 ※추정: 보스 그리드와 동일하게 체크 아이콘 또는 행 비활성화 처리로 유추한다.

### 5.5 화면 C — 주간·시즌미션 탭

#### 5.5.1 주간 성장 미션 (박스형, 상단 고정)
- 보상 코인(예: 1,500) + **"주간 최대 1회"** 라벨 + 챌린저스 패스 연계 구매 버튼(**"주간 심층 패스 0개 [구매하기]"**, 본 문서 범위 밖 — 챌린저스 패스 시스템)
- 3개 조건 중 **택1 달성**으로 완료 처리:
  - 레벨 범위 몬스터 처치 (0/5,000)
  - 몬스터파크 완료 (0/6)
  - 심볼 일일 퀘스트 완료 (0/12)
- 안내 문구: "3개의 미션 중 하나만 달성하여도 미션 완료가 가능합니다."
- **[완료하기]** 버튼: 조건 미충족 시 비활성, 충족 시 활성 → 클릭 시 즉시 지급. 완료 후에는 박스 텍스트가 **"이번 주 미션 완료!"**로 전환된다.

#### 5.5.2 시즌 미션 테이블
컬럼: `카테고리 | 미션 리스트 | 챌린저스 코인 | 달성 비율`
- 각 행에 펼침 화살표(▶)가 있어 클릭 시 상세 조건을 확인할 수 있다.
- **달성 비율(%)은 개인 진행도가 아니라 전체 유저 대비 달성 비율(글로벌 통계)**이다. 안내 문구: "달성 비율은 브론즈 티어 달성 이후부터 집계됩니다."
- 완료된 미션은 펼침 화살표/비율 영역이 **"CLEAR"** 텍스트 배지로 대체되고, 행 전체 텍스트가 회색으로 흐려진다 (예: "어빌리티 유니크 강화 — CLEAR — 98.07%"). CLEAR 배지 표시 후에도 달성 비율(글로벌 통계)은 계속 갱신되어 표시된다.

### 5.6 팝업 플로우 — 보상 수령
'받기' 버튼 클릭 시, 보상의 수량 유형에 따라 두 갈래로 분기한다.

```mermaid
flowchart TD
    A["보상 슬롯 '받기' 클릭"] --> B{수량 배지가 있는\n스택형 보상인가?}
    B -- 아니오 (단일 수령) --> D["수령 확인 팝업\n'받으시겠습니까?'"]
    B -- 예 (예: x100, x300) --> C["수량 입력 팝업\n'몇 개 받으시겠습니까?' 숫자 입력"]
    C --> D2["수령 확인 팝업\n'입력한 개수를 지금 받으시겠습니까?'"]
    D -- 확인 --> E[즉시 지급]
    D -- 취소 --> Z[팝업 닫힘, 상태 변화 없음]
    D2 -- 확인 --> E
    D2 -- 취소 --> Z
    E --> F{해당 슬롯의\n전체 수량 소진?}
    F -- 예 --> G["아이콘에 체크마크(✓) 오버레이,\n버튼 소멸"]
    F -- 아니오 --> H[잔여 수량 표시 갱신,\n'받기' 버튼 유지]
```

- **팝업 A (수량 입력)**: 스택형 보상(아이콘에 배지 수량 표시)에서만 노출. 숫자 입력 필드 + [확인]/[취소]. 최대 입력값은 잔여 보유 가능 수량으로 제한된다 ※추정.
- **팝업 B (수령 확인)**: 모든 수령 시도에 공통 노출. 단일 보상은 "받으시겠습니까?", 스택형은 팝업 A에서 입력한 수량을 반영해 "OO개를 받으시겠습니까?"로 문구가 달라진다.
- 확인 시 지급은 **즉시(비동기 대기 없이)** 처리되며, 전량 수령 완료 시에만 아이콘이 체크 상태로 바뀐다. 부분 수령 상태에서는 '받기' 버튼이 남아 있어 잔여분을 추가로 수령할 수 있다.

### 5.8 알림·연출 (수정)
- N-01. ~~미션 완료 시 토스트 알림~~ → **삭제**. 보스/레벨 미션 완료는 그리드 체크마크 갱신으로만 표시되며, 별도 토스트는 캡처에서 확인되지 않았다.
- N-02. ~~티어 승급 전용 연출~~ → **삭제**. 좌측 패널 조용한 갱신만 존재 (5.2.1).
- N-03. 포인트 충족·관문 미충족 상태의 별도 안내 배너 → ※미확인. 좌측 패널은 여전히 하위 티어 엠블럼을 표시하는 것으로 갈음될 가능성이 높다 (배너 없이 '왜 안 올랐는지'는 3줄 고정 안내(5.3.3)로 유추하게 하는 설계일 수 있음, ※추정).
- N-04. 랭킹 정원 임박 강조 표시 → ※미확인. 별도 랭킹 UI 자체가 미확인이므로 함께 보류.

## 부록 A. 분석 노트 (참고용 — 시스템 명세 아님)

> 아래 내용은 수치 설계에 대한 해석과 기대 효과 가설로, 개발·QA가 구현 기준으로 참조할 명세가 아니라 기획 의도를 이해하기 위한 **분석 메모**다. 본 문서의 명세(3~8장)와 성격이 다름을 명확히 하기 위해 부록으로 분리한다.

### A.1 밸런스 검증 (수치 설계 분석)
- 슈퍼챌린저 요구 90,000점은 최대 포인트 138,000점의 약 65%로, 최상위 보스(칼로스·대적자·카링급) 없이도 **중상위 보스 전체 격파 + 285레벨 내외**로 도달 가능한 수치다. 즉 포인트 컷 자체는 '넓은 문'으로 두고, 실질 관문을 하드 메이린(환산 주스탯 약 4.7만)에 위임하는 구조로 해석할 수 있다.
- 마스터 70,000점 역시 노멀 메이린(전투력 약 3,500만) 격파 스펙이면 자연 달성되는 수준으로, 포인트와 관문의 난이도 곡선이 상호 보완되도록 배치된 것으로 보인다. 포인트가 병목이 되는 구간(플래티넘 20,000 → 에메랄드 30,000, 다이아몬드 50,000 → 마스터 70,000)은 결계 중형 해금·본 서버 수령 보상 개방과 겹쳐, 정체 구간에 보상 밀도를 높인 설계로 추정된다.
- 챌린저스4의 랭킹 정원 50명은 1~3월드(각 999명) 대비 약 5% 수준으로, 리부트계 월드의 인구·경쟁 강도에 맞춘 별도 스케일링으로 보인다.
