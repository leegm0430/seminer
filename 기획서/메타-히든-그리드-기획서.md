## 1. 메타 진행 — 도전과제 & 언락

### 1.1 설계 원칙 (역기획서 §10)

- **죽음 = 진행**: 실패한 런에도 도전과제가 남는다.
- **다양성 확장형 언락**: 해금 보상은 파워업 지급이 아니라 **아이템 풀 확장 + 캐릭터 추가** — 게임이 강해지는 게 아니라 넓어진다.
- 잠긴 아이템은 모든 풀에서 제외되며, 해금 즉시 다음 런부터 등장.

### 1.2 도전과제 9종

| # | 도전과제 | 조건 | 해금 보상 |
|---|---|---|---|
| 1 | 🏆 첫 걸음 | 보스 1회 처치 | 🥋 검은 띠 + **그리드 모드** |
| 2 | ⛏️ 동굴 탐험가 | B3 도달 | ⚙️ 태엽 심장 |
| 3 | 🌑 심연을 보다 | B5 도달 | 🎆 유성우 |
| 4 | 👑 정복자 | B8 보스 처치 | 👑 왕관 + **캐릭터: 유령 아이** |
| 5 | 😈 거래의 대가 | 악마 거래 1회 | **캐릭터: 검은 아이** |
| 6 | 🔍 탐정 | 비밀방 3회 발견 (누적) | 🔮 수정 구슬 |
| 7 | 🎒 수집가 | 한 판에 아이템 10개 | 🎁 판도라 상자 |
| 8 | 💰 탐욕 정복 | 그리드 모드 클리어 | 🐐 염소 머리 |
| 9 | 👁️ 숨겨진 공포 | 히든 보스 처치 | 💀 사신의 낫 |

- 시작 시 잠긴 것: 아이템 8종(i56, i58, i29, i79, i39, i80, i87, i88), 캐릭터 2종(검은 아이, 유령 아이), 그리드 모드.

### 1.3 언락 코드 (저장 방식)

프로토타입 실행 환경에서 브라우저 저장소를 쓸 수 없으므로, **패스워드 이어하기** 방식을 쓴다.

- 사이드 패널에 현재 진행이 `ISAAC-XXX` 코드로 상시 표시. 도전과제 비트마스크(9비트)를 36진수로 인코딩 + 체크섬 1자.
- 다음 세션에서 코드를 입력하면 해금 상태 복원. 잘못된 코드/체크섬 불일치는 거부.
- 한계: 미달성 도전과제의 **진행 카운터**(비밀방 2/3 등)는 코드에 담지 않는다 — 달성한 것만 저장.
- Unity 버전에서는 이 시스템 대신 일반 세이브 파일을 사용 (코드 방식은 폐기).

## 3. 그리드 모드 — 웨이브 방어 서브 모드

### 3.1 해금 & 진입

- '첫 걸음' 달성으로 해금. 캐릭터 선택 화면에서 `G` 키로 일반/그리드 모드 전환 후 시작.

### 3.2 루프 (역기획서 §11)

```
[탐욕의 소굴 (3개 층)] 방 3개: 전투방(버튼) + 보물방(유료 25¢) + 상점
  💰 버튼을 밟으면 웨이브 시작 (총 8웨이브)
    웨이브 클리어 → 동전 보상 (5 + 웨이브×2¢) + 액티브 1칸
    2웨이브마다 상점 재입고
    5웨이브 이후 → 조기 정산 구멍 등장 (보스 스킵, 안전 이익)
    8웨이브 → 보스 웨이브 (층 보스 / 3층은 🤑 울트라 그리드)
  보스 격파 → 보스 아이템 + 20¢ + 다음 소굴
[3층 울트라 그리드 격파] → 💰 탐욕 정복 엔딩 + 도전과제
```

### 3.3 규칙 차이 (일반 모드 대비)

| 항목 | 그리드 모드 |
|---|---|
| 저주 / 비밀방 / 악마 제단 | 없음 |
| 보물방 | 무료 → **25¢ 유료** (동전 경제 중심) |
| 웨이브 중 문 | 잠김 (기존 방 잠금 규칙 재사용) |
| 핵심 선택 | "한 번 더 밟을 것인가, 조기 정산할 것인가" — 욕심의 수위 조절 |

### 3.4 울트라 그리드 (3층 보스)

10방향 회전 방사 + 3갈래 조준 연사. 특이사항: 주기적으로 **동전을 흘린다** (전투 중 수입 발생 — 탐욕 테마 연출).

## 4. 대체 경로 — 챕터 분기 (v5.5)

역기획서 §5.1의 Repentance 대체 경로(폭우/광산/영묘/시체) 오마주. "가로 확장" — 같은 챕터를 다른 규칙으로.

### 4.1 진입

- **B2 보스 처치 후** 보스방에 🚪 하얀 문 등장. **열쇠 1개**를 소모해 진입 (일회성 선택, 복귀 불가).
- 진입 시 B3부터 대체 트랙으로 전환: 광산 I/II → 영묘 I/II → 시체 I/II.

### 4.2 대체 층의 규칙 (하이 리스크·하이 리턴)

| 항목 | 일반 경로 | 대체 경로 |
|---|---|---|
| 적 체력 | 기준 | **×1.25** |
| 챔피언 등장률 | 10% | **20%** |
| 방당 적 수 | 기준 | **+1** |
| 보물방 | 아이템 1개 | **2개 중 1개 선택** (하나를 집으면 나머지 소멸) |
| 맵 생성 | 시드 기준 | 별도 시드 솔트 (같은 시드라도 다른 지형) |
| 테마 | 챕터 기본 | 전용 팔레트 (광산 황금빛 / 영묘 청회색 / 시체 병든 녹색) |

### 4.3 최종 보스: 🤰 마더 (시체 II)

- 체력 420. 패턴: 부채꼴 5발 조준 사격 + 차저 소환, 체력 50% 이하 광폭화(이동 가속 + 10방향 회전 방사 추가).
- 처치 시 **대체 엔딩** "어머니를 넘어섰다" + 도전과제 🧵 **어머니의 그림자** → 신규 아이템 **탯줄**(i95, 수호+공격 복합 패밀리어) 해금.
- 대체 경로에는 히든 포탈이 없다 — 진 엔딩은 일반 경로 전용 (엔딩 3종 분리: 일반/대체/진).

### 4.4 도전과제 갱신

총 **10종** (기존 9종 + 어머니의 그림자). 언락 코드는 10비트 마스크로 자동 확장 (기존 코드 호환).
