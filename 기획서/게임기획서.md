## 1. 게임 개요

플레이어들은 **하나의 공유 은행 계좌**를 가진 도박꾼 일당이다. 사채업자(Loan Shark)에게 빌린
막대한 빚을 갚기 위해 매일 카지노에 출근해 **5분짜리 하루** 동안 도박으로 돈을 불려야 한다.
하루가 끝날 때마다 사채업자가 요구하는 **할당량(Quota)** 을 채우지 못하면 그 자리에서 게임 오버.
할당량을 채우면 **티켓**을 보상으로 받아 다음 날을 유리하게 만들 아이템을 살 수 있다.

핵심 재미는 세 가지다.

1. **공유 자금의 긴장감** — 내 배팅 실수가 곧 팀 전체의 파산. "야 그만해!" / "한 번만 더!"의 아수라장.
2. **리스크 선택** — 안전하게 조금씩 벌 것인가, 남은 시간 30초에 올인할 것인가.
3. **카지노 정복** — 16종의 카지노 게임을 마스터하며 4개 층을 정복하고 빚을 청산.

### 원작(GWYF) 핵심 스펙 요약 (리서치 결과)

- 1~6인 온라인 협동, 친구 전용 멀티, 근접 보이스챗
- **17종의 운 게임**(본 기획서는 확인된 16종 구현), 15종 이상의 수상한 아이템
- 4개의 테마 카지노 층, 5분 데일리 할당량 루프, 엔딩 3종, 도전과제 55개
- 시작 은행 $1,000 / 1일차 할당량 $1,200 수준, 초과 달성 시 보너스(약 17%) 보상
- 티켓 획득: 할당량 달성 + 초과 보너스 + 사채업자 챌린지 + (신체 부위 판매…)
- 티켓 사용: 중고 상점(영구 코스메틱) / 트레일러(1일용 강화 아이템)

## 2. 코어 게임 루프

```
[로비] → 방 생성/참가 (P2P) → 게임 시작
   ↓
[하루 시작] Day N — 할당량 공지, 5분 타이머 시작
   ↓
[카지노] 각자 흩어져 16종 게임 중 원하는 것을 플레이
   │        · 모든 배팅/승리는 공유 은행에 실시간 반영
   │        · 활동 피드로 서로의 승패가 전원에게 중계됨
   ↓
[하루 종료] 타이머 0 또는 전원 조기 퇴근
   ├─ 은행 < 할당량 → ❌ 게임 오버 (사채업자 엔딩)
   └─ 은행 ≥ 할당량 → ✅ 할당량 납부(차감) + 티켓 지급
        ↓
[상점] 티켓으로 다음 날 아이템 구매 (전체 공유 효과)
   ↓
[다음 날] 할당량 ×1.6 상승, 새 층 해금 → 반복
   ↓
[엔딩] 7일 생존 = 빚 청산 엔딩 / 파산 = 배드 엔딩 / 누적 잭팟 = 히든 엔딩
```

## 3. 카지노 게임 16종 상세

각 게임은 `배팅 → 진행 → 판정 → 정산(공유 은행 반영)` 구조를 따른다.
모든 게임에는 약 3~5%의 하우스 엣지를 둔다. (원작의 "카지노는 원래 손해" 감성 유지)

### 분류

- 🍀 **순수 운**: 슬롯, 오리 경주, 머니 휠, 행운의 바퀴, 플링코, 크랩스
- 🧠 **전략/판단**: 블랙잭, 바카라, 1인 포커, 하이로우
- ⚖️ **운+선택(캐시아웃형)**: 크래시, 마인스위퍼, 드래곤 타워, 펭귄 크로스
- 🎯 **선택+운**: 룰렛, 케노

---

### 3.1 슬롯 (Slots) 🍀 — 1F

- **방식**: 배팅 후 릴 3개가 회전. 결과는 완전 랜덤.
- **심볼**: 🍒 🍋 🔔 💎 7️⃣ (가중치: 체리30, 레몬28, 벨22, 다이아14, 세븐6)
- **배당표**:
  - 7️⃣×3 = ×50 / 💎×3 = ×20 / 🔔×3 = ×10 / 🍋×3 = ×6 / 🍒×3 = ×4
  - 아무거나 2개 일치 = ×1.5 / 불일치 = 0
- **전략**: 없음. 소액 다회전 권장. (원작 가이드: "최소 배팅으로만")
- **구현 스펙**: 릴 회전 애니메이션 0.6초 간격 순차 정지. RNG는 가중치 테이블 추첨.

### 3.2 룰렛 (Roulette) 🎯 — 1F

- **방식**: 유러피언 룰렛(0~36, 싱글 제로). 칩을 놓고 스핀.
- **배팅 종류 / 배당**:
  - 빨강/검정, 홀/짝 = ×2 (확률 48.6%)
  - 더즌(1-12/13-24/25-36) = ×3
  - 싱글 넘버 = ×36
- **전략**: 색 배팅이 반반에 가장 가까워 안정적. 넘버 배팅은 아이템(손실 보호)과 조합.
- **구현 스펙**: 휠 회전 애니메이션 후 결과 표시. 복수 배팅 동시 가능.

### 3.3 오리 경주 (Duck Race) 🍀 — 1F

- **방식**: 오리 4마리 중 1마리를 골라 배팅. 오리들이 트랙을 랜덤 가속으로 질주.
- **배당**: 승리 시 ×3.8 (공정 배당 ×4 대비 하우스 엣지 5%)
- **전략**: 예측 불가. 원작에서는 "밈 게임 / 자포자기 스파이크"용.
- **구현 스펙**: 프레임마다 각 오리에 랜덤 속도 부여, 실시간 레이스 연출 (~5초). 승자는 시작 시 미리 추첨하지 않고 물리 결과 그대로 사용.

### 3.4 머니 휠 (Money Wheel) 🍀 — 1F

- **방식**: 색깔 칸으로 나뉜 큰 휠. 어느 색에 멈출지 예측.
- **칸 구성(총 52칸) / 배당**:
  - 🔵 파랑 24칸 = ×2 / 🟢 초록 15칸 = ×3 / 🔴 빨강 9칸 = ×5
  - 🟡 골드 3칸 = ×15 / 🃏 조커 1칸 = ×45
- **전략**: 파랑 위주 소액 배팅. 조커는 로또.
- **구현 스펙**: 휠 스핀 연출, 복수 색 동시 배팅 가능.

### 3.5 행운의 바퀴 (Wheel of Fortune) 🍀 — 3F

- **방식**: 배팅 후 바퀴를 돌려 나온 배수를 그대로 받는다. (색 예측 없음 — 머니 휠과의 차별점)
- **칸 구성(24칸)**: ×0 →8칸, ×1.2 →6칸, ×1.5 →4칸, ×2 →3칸, ×5 →2칸, ×20 →1칸
- **기대값**: 약 0.96
- **전략**: 없음. 순수 운. 최소 배팅 권장.
- **구현 스펙**: 원판 회전 후 포인터 칸 판정.

### 3.6 하이로우 (HiLo) 🧠 — 3F

- **방식**: 현재 카드보다 다음 카드가 **높을지/낮을지** 예측. 맞출 때마다 배수가 누적되고, 언제든 캐시아웃 가능. 틀리면 전액 손실.
- **배수 계산**: 남은 확률의 역수 × 0.96 (예: 현재 카드 3에서 "높다" 선택 시 낮은 배수, "낮다" 선택 시 높은 배수). 동일 숫자는 무승부(패스).
- **전략**: 극단 카드(2~4, J~A)에서만 진행하고 중간 카드는 스킵… 이지만 스킵 기능은 없으므로 애매하면 캐시아웃. 원작에서 "꾸준히 이기기 가장 어려운 게임" 평가.
- **구현 스펙**: 52장 덱, 카드 공개 연출, 누적 배수 표시, 캐시아웃 버튼.

### 3.7 블랙잭 (Blackjack) 🧠 — 2F

- **방식**: 딜러와 1:1. 21에 가깝게. 히트/스탠드/더블 지원 (스플릿은 Unity 버전에서).
- **규칙**: 딜러는 17 이상 스탠드(소프트17 스탠드). 블랙잭 배당 ×2.5. 일반 승 ×2. 푸시는 환불.
- **전략**: 원작 가이드 기준 "15 이상 스탠드, 15 미만 히트, 20이면 더블(?)" — 실제로는 기본 전략표 사용 권장. 카지노 게임 중 기대값 최고 (~99%).
- **구현 스펙**: 6덱 슈, 카드 딜링 애니메이션, 딜러 홀카드 공개 연출.

### 3.8 바카라 (Baccarat) 🧠 — 2F

- **방식**: 플레이어/뱅커 중 9에 가까운 쪽이 승리. 어느 쪽이 이길지에 배팅.
- **배당**: 플레이어 ×2 / 뱅커 ×1.95 (5% 커미션) / 타이 ×9
- **규칙**: 정식 서드카드 룰 적용 (플레이어 0-5 히트, 뱅커는 플레이어 서드카드에 따른 표준 표).
- **전략**: 뱅커 배팅이 통계상 최유리. 타이는 함정. 원작 가이드: "일관된 예측 유지, 공격적 증액 금지."
- **구현 스펙**: 카드 오픈 연출, 서드카드 룰 자동 처리.

### 3.9 1인 포커 (Video Poker) 🧠 — 2F

- **방식**: 카드 5장을 받고, 원하는 카드를 홀드한 뒤 1회 교환. 최종 족보로 배당.
- **배당표 (Jacks or Better 기반)**:
  - 로열 플러시 ×250 / 스트레이트 플러시 ×50 / 포카드 ×25 / 풀하우스 ×9
  - 플러시 ×6 / 스트레이트 ×4 / 트리플 ×3 / 투페어 ×2 / J 이상 원페어 ×1(환불)
- **전략**: 원작 가이드 "최소 원페어를 만든 뒤 진행하라." 하이카드 홀드 기본기.
- **구현 스펙**: 카드 클릭으로 홀드 토글 → 드로우 → 족보 자동 판정.

### 3.10 스트리트 크랩스 (Street Craps) 🍀 — 2F

- **방식**: 주사위 2개. 첫 굴림(컴아웃)에서 7/11이면 즉시 승, 2/3/12면 즉시 패. 그 외 숫자는 '포인트'가 되며, 7이 나오기 전에 포인트를 다시 굴리면 승리.
- **배당**: ×2 (패스라인 기준, 기대값 98.6% — 룰상 플레이어에게 매우 유리한 편)
- **전략**: 원작 가이드 "패배 조건만 이해하면 유리한 게임." 배팅 후 자동 진행.
- **구현 스펙**: 주사위 굴림 연출 반복, 포인트 상태 표시.

### 3.11 케노 (Keno) 🎯 — 3F

- **방식**: 40칸 타일 중 최대 8개 선택 → 다이아몬드 10개가 랜덤 칸에 떨어짐 → 적중 수만큼 배당.
- **배당표 (선택 수 × 적중 수)**: 예) 4개 선택: 2적중 ×1, 3적중 ×5, 4적중 ×40 / 8개 선택: 4적중 ×2, 5적중 ×6, 6적중 ×30, 7적중 ×120, 8적중 ×500
- **전략**: 원작 가이드 "일관된 타일 선택 권장." 선택 수가 적을수록 변동성 낮음.
- **구현 스펙**: 타일 그리드 클릭 선택, 다이아 낙하 연출, 배당표 실시간 표시.

### 3.12 플링코 (Plinko) 🍀 — 3F

- **방식**: 핀 보드 위에서 공을 떨어뜨림. 공이 핀에 튕기며 내려가 바닥 슬롯의 배수를 받는다.
- **구성**: 12줄 핀 → 바닥 13슬롯. 배수(양끝→중앙): ×22, ×8, ×3, ×1.6, ×1, ×0.7, ×0.5(중앙), 대칭 (이항분포 기준 기대값 ≈ 0.95 검증 완료)
- **전략**: 중앙 낙하 확률이 압도적(이항분포). 원작 가이드 "여러 라운드에 분산 배팅."
- **구현 스펙**: 각 줄에서 좌/우 50% 랜덤, 실제 낙하 애니메이션. 연속 드롭 가능.

### 3.13 크래시 (Crash) ⚖️ — 4F

- **방식**: 로켓이 발사되며 배수가 ×1.00부터 상승. **터지기 전에 캐시아웃**하면 해당 배수 획득, 놓치면 전액 손실.
- **크래시 포인트 분포**: `max(1.00, 0.97 / (1 - r))` (r = 균등난수) → 즉시 터짐 ~3%, 중앙값 ≈ ×1.94
- **전략**: 원작 가이드 "큰 배수 욕심 대신 잦은 저배수 캐시아웃으로 점진적 수익."
- **구현 스펙**: 배수 실시간 상승 그래프, 캐시아웃 버튼, 최근 크래시 기록 표시.

### 3.14 마인스위퍼 / 마인스 (Mines) ⚖️ — 4F

- **방식**: 5×5 그리드에 지뢰 N개(1~24, 플레이어 설정). 안전 칸을 열 때마다 배수 상승, 지뢰를 밟으면 전액 손실. 언제든 캐시아웃.
- **배수 계산**: 공정 확률 역수 누적 × 0.97 (지뢰 수가 많을수록 칸당 배수 급상승)
- **전략**: 원작 가이드 "지뢰 수를 높게 설정했다면 일찍 캐시아웃하라."
- **구현 스펙**: 지뢰 수 슬라이더, 칸 오픈 연출(💎/💣), 다음 칸 배수 미리보기.

### 3.15 드래곤 타워 (Dragon Tower) ⚖️ — 4F

- **방식**: 9층 타워. 각 층에 타일 3개, 그중 1개는 드래곤(💀). 안전 타일을 골라 오를수록 배수 상승. 드래곤을 고르면 전액 손실. 언제든 캐시아웃.
- **배수**: 층당 ×1.44 누적 (공정 ×1.5 × 0.96), 9층 완주 시 약 ×26.6
- **전략**: 원작에서는 "드래곤 눈 위치 암기" 같은 편법이 있었으나 프로토타입은 층마다 재추첨. 3~5층 캐시아웃이 안정선.
- **구현 스펙**: 타워 UI 아래→위, 타일 선택 연출, 층별 누적 배수 표시.

### 3.16 펭귄 크로스 (Penguin Cross) ⚖️ — 4F

- **방식**: 펭귄이 빙판 차선을 한 칸씩 건넌다. 한 칸 전진할 때마다 배수 상승, 얼음이 깨지면(실패) 전액 손실. 언제든 캐시아웃. (치킨 크로스형 래더 게임)
- **구성**: 12차선. n번째 차선 생존 확률 = 92% − n×2% (1차선 90% → 12차선 68%)
- **배수**: 생존 확률 역수 누적 × 0.97 → 12차선 완주 시 약 ×20
- **전략**: 원작 가이드 "초반 소액, 자원 쌓이면 안전하게 증액." 클러치 역전용 게임.
- **구현 스펙**: 펭귄 이동 연출, 차선별 배수 표시, 얼음 깨짐 연출.

## 5. 멀티플레이 설계 (P2P)

### 5.1 아키텍처 — 호스트 권한형 P2P

```
        [호스트 = 방장]  ←  게임 상태의 단일 진실 (은행, 타이머, 일차, 티켓)
        /      |      \
   WebRTC   WebRTC   WebRTC     ← PeerJS (공개 시그널링 서버로 연결 수립)
      /        |        \
 [게스트A]  [게스트B]  [게스트C]   ← 입력 전송 + 상태 수신
```

- **연결**: PeerJS. 호스트가 6자리 방 코드 생성 → 게스트가 코드 입력으로 접속.
- **호스트 권한**: 공유 은행 증감, 타이머, 일차 전환, 할당량 판정, 상점 결제는 모두 호스트가 처리 후 전파.
- **미니게임 RNG**: 프로토타입에서는 플레이하는 클라이언트가 결과를 계산해 정산 요청 (신뢰 기반 — 친구 전용이므로 허용). **Unity 버전에서는 호스트가 RNG 시드/결과를 전담**하여 치팅 차단.

### 5.2 메시지 프로토콜 (프로토타입)

| 타입 | 방향 | 내용 |
|---|---|---|
| `hello` | 게스트→호스트 | 닉네임 등록 |
| `state` | 호스트→전원 | 전체 상태 스냅샷 (은행, 일차, 타이머, 티켓, 인벤토리, 플레이어 목록) |
| `bet` | 게스트→호스트 | 배팅 차감 요청 (호스트가 잔액 검증 후 승인/거절) |
| `payout` | 게스트→호스트 | 승리 정산 요청 |
| `feed` | 호스트→전원 | 활동 피드 ("철수 룰렛 +$400!") |
| `buy` | 게스트→호스트 | 상점 구매 요청 |
| `chat` | 양방향 | 텍스트 채팅 |
| `phase` | 호스트→전원 | 하루 시작/종료/상점/엔딩 전환 |

### 5.3 동기화 정책

- 상태 스냅샷은 변경 시 즉시 + 1초 주기 하트비트로 전파 (타이머 드리프트 보정)
- 게스트의 배팅은 **호스트 승인 전까지 로컬 차감 표시** → 거절 시 롤백 (잔액 부족 레이스 방지)
- 호스트 이탈 시 세션 종료 안내 (호스트 마이그레이션은 Unity 버전 과제)

## 8. Unity 이식 계획 (2차 개발)

1. **씬 구조**: Lobby → Casino(4층 3D 공간, 엘리베이터 이동) → 미니게임은 월드 내 테이블 상호작용
2. **네트워킹**: Netcode for GameObjects + Unity Relay (P2P 개념 유지, 호스트 권한형) — HTML 프로토타입의 메시지 프로토콜을 RPC/NetworkVariable로 1:1 매핑
3. **게임 로직 재사용**: 프로토타입의 판정 로직(배당표, RNG 규칙)을 C#으로 포팅 — 본 기획서의 수치가 단일 소스
4. **원작 감성 추가 요소**: 근접 보이스챗, 캐릭터 커스터마이즈/이모트, 신체 부위 판매(티켓 획득), 사채업자 NPC 챌린지, 물리 기반 소품, 코스메틱 중고상점
5. **검증된 밸런스 이관**: HTML 프로토타입에서 플레이테스트한 할당량 곡선/배당표를 그대로 사용
