# 🩸 The Binding of Isaac — 역기획서 (시스템 분석)

## 1. 게임 정체성 (High Concept)

**"매번 다르게 조합되는 던전에서, 아이템을 주워 눈물(총알)을 괴물로 바꿔가는 게임."**

아이작의 본질은 세 문장으로 요약된다.

1. **절차 생성 던전** — 매 판 층 구조, 방, 적, 아이템이 새로 뽑힌다. 같은 판은 두 번 없다.
2. **아이템 스태킹 & 시너지** — 700종의 아이템이 무제한으로 중첩·상호작용한다. 빌드의 화학 반응이 곧 재미.
3. **영구 죽음 + 메타 진행** — 죽으면 그 판은 끝이지만, 죽음 사이에 **언락**이 쌓여 게임 자체가 넓어진다.

여기에 정체성을 완성하는 네 번째 축이 있다. **리스크-보상 선택의 상시화** — 체력을 지불하는 악마 거래, 피를 깎는 저주 방, 아이템 2개 중 1개만 갖는 보스전 선택 등, 게임 내내 "얼마나 욕심낼 것인가"를 묻는다.

### 톤 & 테마

성경의 '이삭의 번제' 설화를 뒤틀어, 광신적인 엄마에게 쫓겨 지하실로 도망친 소년의 이야기. 그로테스크(배설물, 기형, 신체 훼손)와 블랙유머, 종교적 상징, 아동 학대라는 무거운 주제를 크레용 낙서풍 아트로 감싼 **부조화의 미학**. 스토리는 컷신 파편으로만 제시되어 해석의 여지를 남긴다 — 서사가 시스템을 방해하지 않는 구조.

## 2. 코어 게임플레이 (Moment-to-Moment)

### 2.1 조작 체계 — 트윈스틱

| 입력 | 기능 |
|---|---|
| 이동 (WASD/좌스틱) | 8방향 이동. 이동과 조준이 완전히 분리 |
| 공격 (방향키/우스틱) | 4방향(아날로그 보정 있음) 눈물 발사. **누르고 있으면 연사** |
| 아이템 사용 (Space) | 액티브 아이템 발동 (충전제) |
| 폭탄 (E/Shift) | 소지한 폭탄 설치. 지형 파괴 + 광역 피해 |
| 카드/알약 사용 (Q) | 소모품 슬롯 사용 |
| 드롭 (Ctrl 홀드) | 장신구/카드 버리기 |

- 조작 난이도를 낮게(이동+조준+버튼 3개), **판단 난이도를 높게** 설계한 전형. 컨트롤 자체는 5분이면 배운다.
- 공격이 '눈물'인 것은 테마(우는 아이)와 메커니즘(투사체)의 결합 — 모든 공격 아이템이 "눈물이 ~로 변한다"는 일관된 문법을 가진다.

### 2.2 방(Room) 단위 전투 구조

던전은 **방의 그리드**로 구성된다. 이 구조가 게임의 리듬을 만든다.

```
방 진입 → 문 잠김 → 적 전멸 → 문 열림 + 보상 드롭(확률) → 다음 방 선택
```

- **한 화면 = 한 전투.** 방에 들어가면 문이 잠기고, 적을 모두 잡아야 열린다. 전투의 시작과 끝이 명확한 **마이크로 인카운터** 단위.
- 클리어한 방은 재진입해도 적이 리스폰되지 않는다 (일부 저주 제외) → 탐색은 자유, 전투는 1회성.
- 방 크기 변형: 1×1(기본), 1×2, 2×1, 2×2, L자형 등. 큰 방은 미니맵에서도 크게 표시.
- 방 내부는 **수작업 디자인**(수천 종의 방 레이아웃 풀)이고, 방의 '배치'만 절차 생성 → *"조립은 랜덤, 부품은 수제"* 방식. 절차 생성의 단조로움을 수제 레벨 디자인으로 상쇄하는 핵심 기법.

### 2.3 피격과 체력

- 피격 시 무적시간(약 1초) 부여. 접촉 피해가 기본이라 **위치 선정이 곧 방어**.
- 피해 단위는 하트 반 칸(후반 층은 한 칸). 회복 수단이 귀해 **체력 = 최상위 자원**.
- 이 "체력의 희소성"이 악마 거래(체력 지불)와 저주 방(피 내고 입장) 같은 리스크 시스템의 기반이 된다.

## 3. 코어 루프

### 3.1 3층 구조 루프

```
[초단기: 초 단위] 방 전투
  적 패턴 회피 → 전멸 → 보상 (동전/열쇠/폭탄/하트 드롭)
        ↓ 반복
[중기: 분 단위] 층(Floor) 공략
  맵 탐색 → 보물방(아이템) / 상점 / 비밀방 수급 → 보스전 → 아이템 + 다음 층
        ↓ 반복 (6~11층)
[장기: 판 단위] 런(Run)
  빌드 완성 → 최종 보스 → 클리어 or 사망
        ↓
[메타: 계정 단위] 언락
  컴플리션 마크/도전과제 달성 → 새 아이템·캐릭터·루트가 풀에 추가
  → 다음 런이 더 넓어짐
```

### 3.2 층 공략의 표준 흐름 (중기 루프 상세)

1. 층 시작 → 미니맵으로 인접 방 확인
2. 일반 방을 돌며 자원(동전·폭탄·열쇠) 수급
3. **보물방**(열쇠 1개 필요)에서 이번 층의 핵심 아이템 획득
4. 상점·비밀방·특수 방을 자원 상황에 맞게 취사선택
5. **보스방** → 보스전 → 보스 아이템(스탯 업 위주) + 다음 층 입구
6. (조건 충족 시) 악마 방/천사 방 입장 기회

> 설계 포인트: 보물방=빌드의 축(변화), 보스 보상=스탯(성장)으로 **보상의 성격을 방마다 분리**해 두었다. 매 층 "빌드가 바뀌는 재미"와 "숫자가 오르는 재미"를 둘 다 보장하는 장치.

### 3.3 세션 페이싱

- 1개 층 = 약 3~7분. 보스까지 총 6층(기본 엔딩)이면 30분 내외.
- 후반 루트(메가 사탄, 딜리리엄, 비스트)는 조건 분기가 붙어 40~70분.
- **타임어택 요소**: 보스 러시(엄마전까지 20분 이내), 허쉬(엄마 심장전까지 30분 이내) — 잘하는 플레이어에게 "빨리 도는" 추가 목표를 부여해 숙련자의 플레이 밀도를 높인다.

## 4. 절차적 생성 시스템

### 4.1 층(Floor) 생성 규칙

1. 시작 방을 중심으로 그리드 위에 방을 **가지 뻗기** 방식으로 배치 (층이 깊어질수록 방 개수 증가)
2. **막다른 방(dead end)** 에 특수 방을 배정: 보스방은 시작 방에서 가장 먼 막다른 곳, 보물방·상점·비밀방 등은 규칙에 따라 배치
3. 비밀방은 "인접 방이 3~4개인 빈 칸"에 숨겨짐 → 미니맵을 읽으면 **추론으로 위치를 좁힐 수 있다** (폭탄으로 벽을 뚫어 입장)
4. 각 방 슬롯에 해당 층 테마의 방 레이아웃 풀에서 하나를 추첨
5. 시드(Seed) 기반: 같은 시드 = 같은 던전. 시드 공유/데일리 런의 기반 기술

> 설계 포인트: 비밀방 규칙이 대표적인 **"랜덤 속의 학습 가능 규칙"**. 절차 생성이지만 생성 규칙 자체를 플레이어가 학습해 실력으로 전환할 수 있게 한다. 모티브 게임에서도 "규칙이 보이는 랜덤"은 반드시 챙겨야 할 설계 철학.

### 4.2 방 종류 카탈로그 (주요)

| 방 | 입장 조건 | 내용물 | 설계 역할 |
|---|---|---|---|
| 일반 방 | - | 적/장애물/소량 드롭 | 기본 전투 단위 |
| 보스 방 | - | 층 보스 + 아이템 | 층의 마침표 |
| 보물방 🖼️ | 열쇠 1 (1~2층은 무료 아님, 기본 잠김) | 아이템 1개 (Repentance: 선택지 2개 중 1개인 경우도) | 빌드의 축 |
| 상점 💰 | 열쇠 1 | 아이템/소모품 판매 (15~99센트) | 경제 순환 |
| 비밀 방 | 폭탄으로 벽 파괴 | 랜덤 (아이템/픽업/입구) | 탐색 보상, 추론 재미 |
| 초비밀 방 | 비밀방 규칙의 역(고립된 칸) | 고급 보상 | 하드코어 탐색 |
| 저주 방 👿 | 입장/퇴장 시 피해 (가시문) | 레드 체스트, 데빌 아이템류 | 체력↔보상 교환 |
| 희생 방 | 가시에 스스로 피격 | 피해 누적 시 보상 상승 (12회: 천사방/다크룸 이동) | 체력 도박 |
| 도전 방 ⚔️ | 체력 조건 (하트 1칸 이하 등) | 웨이브 전투 → 보상 | 전투력 검증 |
| 아케이드 🎰 | 동전 | 슬롯머신, 거지, 피 헌혈기 | 자원 도박 |
| 악마 방 😈 | 보스전 노히트 등 확률 | **체력을 지불**하고 아이템 구매 | 핵심 리스크 거래 |
| 천사 방 😇 | 악마 거래 거절 시 대체 등장 | 무료 아이템 + 성물 | 리스크 회피 보상 |
| 도서관 📚 | 열쇠 1 | 책(액티브) 아이템 | 풀 세분화 |
| 플라네타리움 🔭 | 확률 (보물방 스킵 시 상승) | 별자리(강력) 아이템 | 상급자용 대체 루트 |
| 다이스 방 🎲 | 열쇠 2 | 층/아이템 리롤 | 런 전체 재추첨 |
| 금고/침실 등 | 폭탄/열쇠 | 픽업 뭉치, 회복 | 소소한 보상 |

### 4.3 저주(Curse) 시스템

층 진입 시 확률로 디버프 부여: 어둠(시야 축소), 미로(2개 층 연결), 상실(미니맵 삭제), 눈멂(아이템이 ?로 표시), 미지(체력 표시 삭제) 등.
→ **정보를 빼앗는 방식의 난이도 변주.** 전투력이 아니라 플레이어의 '계획 능력'을 공격한다.

## 5. 스테이지 구조 — 챕터와 분기

### 5.1 기본 진행 (Repentance 기준)

```
Ch.1 지하실(Basement)   ×2층  ── 변형: 저장고 / 불타는 지하실 │ 대체: 폭우(Downpour)/찌꺼기(Dross)
Ch.2 동굴(Caves)        ×2층  ── 변형: 지하묘지 / 침수 동굴   │ 대체: 광산(Mines)/잿구덩이(Ashpit)
Ch.3 심연(Depths)       ×2층  ── 변형: 네크로폴리스 등        │ 대체: 영묘(Mausoleum)/게헨나
        └─ 보스: 엄마(Mom) ← 최초의 스토리 보스
Ch.4 자궁(Womb)         ×2층  ── 변형: 자궁 내부 등           │ 대체: 시체(Corpse)
        └─ 보스: 엄마의 심장 / It Lives
        ├─ (20분↑ 조건) 푸른 자궁 → 허쉬(Hush)
Ch.5 분기: 지옥(Sheol) → 사탄  /  성당(Cathedral) → 아이작
Ch.6 분기: 다크 룸 → 어린 양(The Lamb)  /  체스트 → ???(블루 베이비)
        ├─ (열쇠 조각 2개) 메가 사탄
        ├─ (보이드 진입) 딜리리엄(Delirium)
대체 경로 종점: 시체 → 마더(Mother)
        └─ (영묘에서 문 개방) 승천 루트 → 홈(Home) → 도그마 → 비스트(The Beast) = 진 최종 엔딩
```

### 5.2 구조 분석

- **같은 챕터의 층 변형(팔레트 스왑 + 적 풀 변화)** 으로 시각적 다양성을 확보하고, **대체 경로(Repentance)** 로 완전히 다른 루트를 추가 — 콘텐츠 확장이 "세로(더 깊게)"와 "가로(다른 길)" 양방향.
- 최종 보스가 하나가 아니라 **7종+ (사탄/아이작/???/램/메가사탄/딜리리엄/마더/비스트)** 이고 각각 입장 조건이 다르다 → "오늘은 어느 엔딩을 노릴까"가 런 시작 시점의 선택이 된다.
- 후반 루트일수록 **조건부 입장**(열쇠 조각, 타임어택, 특정 아이템)을 걸어 목표 자체를 언락 진행과 얽어 놓았다.
- 엔딩 22종. 대부분 "새 언락의 예고편" 역할을 하는 짧은 컷신.

## 6. 캐릭터 시스템

### 6.1 스탯 6종 — 모든 성장의 축

| 스탯 | 효과 | 비고 |
|---|---|---|
| 데미지 (Damage) | 눈물 1발의 피해량 | 기본 3.5, 증가분은 **체감 곡선**(√ 기반)으로 환산 — 무한 스택해도 완만해짐 |
| 연사 (Tears) | 발사 딜레이 감소 | 역시 체감 곡선 + 상한 존재. DPS = 데미지 × 연사가 빌드의 뼈대 |
| 이동속도 (Speed) | 이동 속도 | 상한 2.0. 회피 능력과 직결 |
| 사거리 (Range) | 눈물 지속 거리 | |
| 탄속 (Shot Speed) | 눈물 비행 속도 | 낮으면 오히려 유리한 빌드도 존재 |
| 행운 (Luck) | 드롭률·확률 효과 발동률 | 확률형 아이템과 시너지 |

> 설계 포인트: 스탯 증가에 **감쇠 곡선**을 깔아 "스탯만 쌓는 빌드"의 상한을 정하고, 그 이상의 파워는 **아이템 시너지(눈물 변형)** 에서 나오게 했다. 숫자 성장과 질적 성장의 역할 분담.

### 6.2 체력 시스템 — 하트의 다층 구조

| 하트 | 특성 |
|---|---|
| ❤️ 레드 하트 | 기본 체력. 하트 용기(container)에 채워짐. 회복 가능 |
| 💙 소울 하트 | 용기 없이 붙는 추가 체력. 회복 불가, 소모성 방어막 |
| 🖤 블랙 하트 | 소울 하트 + 깨질 때 방 전체 피해 |
| 🦴 본 하트 | 용기 자체가 소모품. 레드 하트를 채울 수 있음 |
| 💛 골드 하트 | 피격 시 동전 드롭 |
| 🤍 이터널 하트 | 반 칸. 층 클리어 시 온전한 용기로 승격 |
| 🟢 로튼 하트 | 피격 시 파리 소환 |

- **레드/소울의 이원 구조가 악마 거래의 화폐 시스템과 맞물린다**: 악마 거래는 레드 하트 용기로 지불하므로, 소울 하트 위주 캐릭터(???)는 거래 방식 자체가 달라진다.
- 캐릭터마다 체력 규칙 자체를 바꾼다: 더 로스트(체력 0, 원히트킬), 키퍼(동전이 체력), 베타니(소울 하트를 자원으로 소모).

### 6.3 캐릭터 34종 — "규칙 변형"으로서의 캐릭터

캐릭터 = 스탯 프리셋이 아니라 **게임 규칙의 변형(modifier)**.

| 유형 | 예시 | 변형 방식 |
|---|---|---|
| 표준형 | 아이작, 막달레나, 카인 | 스탯/시작 아이템 차등 (입문용) |
| 자원 규칙 변형 | 키퍼(동전=체력), 베타니(소울하트=위습 자원) | 경제 시스템을 다시 배우게 함 |
| 리스크 극단화 | 더 로스트(체력 없음), 라자루스(1회 부활 전제) | 실력 검증형 |
| 빌드 강제 | 아자젤(단거리 브림스톤), 포가튼(근접 뼈), 리리트(공격 불가, 패밀리어 의존) | 특정 플레이스타일 강제 |
| 타락(Tainted) 17종 | 각 캐릭터의 규칙을 한 번 더 비틂 (T.아이작: 소지 아이템 8개 제한, T.로스트: 아이템 풀 자체가 고품질로 필터링) | 기존 캐릭터의 재해석 = 콘텐츠 재활용의 정석 |

> 설계 포인트: 캐릭터 하나 = 사실상 새로운 모드. 같은 콘텐츠(던전/아이템)를 다른 규칙으로 다시 돌게 만들어 **콘텐츠 수명을 곱셈으로 늘린다**. 타락 캐릭터는 기존 캐릭터 리소스를 재활용하면서 게임플레이만 뒤트는 고효율 확장.

## 7. 아이템 시스템 — 게임의 심장

### 7.1 분류 체계

| 분류 | 슬롯 | 개수 규모 | 특성 |
|---|---|---|---|
| 패시브 | 무제한 스택 | 500종+ | 획득 즉시 영구 적용. 빌드의 본체 |
| 액티브 | 1개 (아이템으로 2개 가능) | 100종+ | 충전식(방 클리어로 충전). 전술 버튼 |
| 장신구(Trinket) | 1개 | 190종+ | 소소한 패시브. 교체 가능 |
| 소모품 | 카드/룬/알약 1슬롯 | 카드·룬 90종+, 알약 13종 | 1회용 효과 |
| 픽업 | 즉시 사용 | 동전/폭탄/열쇠/하트 등 | 자원 |

### 7.2 아이템 풀(Item Pool) — 보상의 성격 제어

아이템은 전역 랜덤이 아니라 **출처별 풀**에서 추첨된다.

- 보물방 풀: 빌드를 바꾸는 변화형 아이템 중심
- 보스 풀: 스탯 업 중심 (층 클리어의 확실한 성장 보장)
- 상점 풀: 유틸리티/경제형
- 악마 방 풀: 강력하지만 사악한 컨셉 (공격 특화)
- 천사 방 풀: 방어/신성 컨셉
- 비밀방, 도서관, 플라네타리움, 저주방, 골든체스트 풀 등 별도 존재
- 같은 아이템이 여러 풀에 속할 수 있고, 한 번 나온 아이템은 그 판에서 풀에서 제거 (중복 방지)

> 설계 포인트: 풀 분리는 **"어디서 얻는 보상인가"에 서사와 기대감을 부여**한다. 악마 방을 열었을 때의 두근거림은 악마 풀의 정체성(고위험 고화력)이 학습되어 있기 때문. 랜덤 보상 게임에서 풀 설계 = 기대 관리 설계.

### 7.3 퀄리티 시스템 (Repentance)

전 아이템에 내부 등급 0~4 부여. 직접 노출되지는 않지만(외부 위키/모드로 확인), T.로스트의 "퀄리티 2 이상만 등장" 같은 규칙, 신성 모독(Sacred Orb)의 저퀄 필터링 등에 사용. → 랜덤성을 캐릭터별로 **필터링**하는 내부 파라미터.

### 7.4 시너지 — 아이작 설계의 정수

- 모든 눈물 변형 아이템은 원칙적으로 **곱연산으로 중첩**된다. 유도(호밍) + 관통 + 브림스톤(레이저) + 분열이 전부 동시 적용되는 식.
- 예외적 조합은 개별 시너지 규칙을 수작업 정의 (브림스톤+테크놀로지 = 회전 레이저 등). Repentance에서 수백 개의 전용 시너지가 추가됨.
- 시너지의 재미 공식: **"각 아이템의 효과를 알고 있어도, 조합 결과는 예측을 초과한다"**. 이것이 700종 아이템의 조합 공간(사실상 무한)을 만든다.
- 변신(Transformation) 시스템: 특정 세트 아이템 3개 수집 시 캐릭터가 변신하며 보너스 (구피=파리 군단, 베엘제붑 등 15종+). **수집에 방향성 부여** — 랜덤 드롭에도 "모으는 목표"를 심는 장치.

### 7.5 정보 은닉과 위키 문화

- 게임 내 아이템 설명은 한 줄 문구("DMG up", "???")뿐. 정확한 효과는 직접 겪거나 외부 위키로 학습.
- 의도된 설계: **미지의 아이템 = 매 획득이 실험**. 커뮤니티 위키/외부 도구(툴팁 모드)가 사실상 공식 보조 시스템으로 자리잡음. Repentance+에서야 게임 내 아이템 설명이 (엄마 처치 후 언락으로) 공식 추가됨.
- 모티브 게임 시사점: 정보 은닉은 초기 신비감을 주지만 진입장벽이 크다. "언락형 도감/설명"이 현대적 절충안.

### 7.6 알약(Pill) — 판마다 섞이는 미니 랜덤

알약 색상별 효과가 **판마다 재배정**된다. 같은 회색 알약이 이번 판엔 체력+1, 다음 판엔 폭탄이 되는 식. 처음 먹을 때만 도박, 이후는 지식 → **런 내부의 학습 사이클**을 하나 더 심어둔 장치.

## 8. 경제 & 리스크-보상 시스템

### 8.1 자원 삼각형: 동전 · 폭탄 · 열쇠

| 자원 | 쓰임 | 긴장 포인트 |
|---|---|---|
| 🪙 동전 | 상점, 아케이드, 거지 | 상점 아이템 vs 도박 |
| 💣 폭탄 | 지형 파괴, **비밀방 개방**, 전투 | 전투에 쓸까 탐색에 쓸까 |
| 🗝️ 열쇠 | 보물방, 상점, 금고 | 이번 층 보물방 vs 다음 층 |

세 자원이 서로 다른 문을 열기 때문에 **"무엇을 포기할 것인가"** 가 층마다 반복된다. 자원이 남아돌지 않도록 드롭률이 조여져 있다.

### 8.2 악마 거래 (Devil Deal) — 대표 리스크 시스템

- 보스 처치 후 확률로 악마 방 문 등장. 확률은 **해당 층에서 피해를 받지 않았는가, 저주 방을 이용했는가** 등의 플레이 행동으로 상승 → 잘한 플레이어에게 더 자주 열린다.
- 아이템의 가격이 돈이 아니라 **하트 용기 1~2개(최대 체력!)**. 강해지는 대가로 죽기 쉬워진다.
- **악마/천사 배타 규칙**: 악마 거래를 한 번이라도 하면 천사 방이 (원칙적으로) 등장하지 않음. 즉 "악마의 힘 vs 천사의 가호 + 메가사탄 열쇠 조각" 노선 선택.
- 이 시스템 하나가 아이작의 리스크-보상 철학을 압축한다: **보상은 언제나 체력(생존)과 교환된다.**

### 8.3 도박 기계·거지 류

슬롯머신(동전→랜덤), 피 헌혈기(체력→동전), 운세 기계, 거지(동전 헌납→아이템), 악마 거지(체력 헌납), 열쇠 장인… 모든 자원이 **다른 자원이나 아이템으로 환전 가능한 도박 창구**를 가진다. 잉여 자원의 소비처를 보장해 경제가 막히지 않는다.

### 8.4 리스크 장치 총정리

| 장치 | 지불 | 보상 |
|---|---|---|
| 악마 거래 | 최대 체력 | 강력한 아이템 |
| 저주 방 | 출입 시 피해 | 레드 체스트/아이템 |
| 희생 방 | 반복 피해 | 누적 보상 + 천사방/다크룸 워프 |
| 피 헌혈기 | 체력 | 동전 |
| 도전 방 | 저체력 입장 조건 | 웨이브전 보상 |
| 보스 러시/허쉬 | 시간 압박 | 추가 보스 + 아이템 |
| ??? 알약 | 미지 효과 | 지식 |

## 9. 보스 & 적 설계

### 9.1 적 설계 문법

- 적 100종+ (Repentance 기준 추가분 포함). 대부분 **단순 행동 규칙 1~2개의 조합** (돌진형, 사격형, 분열형, 소환형, 추적형).
- 개별 적은 단순하지만 **방 레이아웃(장애물/구덩이/가시)과의 조합**으로 난이도를 만든다 — 적 AI가 아니라 배치가 난이도.
- **챔피언 변형**: 일반 적의 색상 변형(더 빠름/분열/폭발 등)으로 적 풀을 저비용 확장.
- 시각 문법의 일관성: 붉은 적=돌진, 떠 있는 적=장애물 무시 등 색·형태가 행동을 예고.

### 9.2 보스 설계

- 보스 100종+. 층별 보스 풀에서 추첨 (같은 층도 매판 다른 보스).
- 패턴은 2~4개로 단순하게, 대신 **보스도 챔피언/변형 존재**.
- 스토리 보스(엄마, 엄마의 심장, 이후 최종 보스들)는 고정 등장으로 **이정표** 역할.
- 최종 보스일수록 기믹 강화: 허쉬(탄막 슈팅화), 딜리리엄(다른 보스로 변신), 도그마→비스트(스크롤 슈팅 전환) — 후반 보스전은 **장르 변주**로 절정감을 연출.

## 10. 메타 진행 — 언락 시스템

### 10.1 구조

죽어도 잃지 않는 것: **도전과제 637개**와 그에 묶인 언락(새 아이템, 캐릭터, 트링켓, 보스, 루트, 엔딩).

- **컴플리션 마크**: 캐릭터별 체크리스트. 주요 보스(엄마의 심장, 아이작, 사탄, ???, 램, 보스러시, 허쉬, 메가사탄, 그리드모드, 딜리리엄, 마더, 비스트) 격파마다 마크가 채워지고 **캐릭터 전용 언락**이 해금. 하드모드 클리어 시 마크에 별도 표시.
- 34캐릭터 × 12마크 = **400개+의 장기 목표 매트릭스**가 자동 생성된다.
- 언락된 아이템은 **아이템 풀에 추가**된다 → 게임이 어려워지는 게 아니라 **넓어진다**. (파워 인플레가 아닌 다양성 인플레)

### 10.2 설계 분석

- "죽음 = 진행"의 심리 전환: 실패한 런에도 도전과제 몇 개는 남는다. 로그라이크의 좌절을 메타 보상으로 완충.
- 언락 순서가 완만한 **온보딩 커브**를 만든다: 초기엔 아이템 풀이 작아 게임이 단순하고, 숙련될수록 풀이 복잡해진다. 언락 시스템 = 난이도 커브 조절 장치.
- 시크릿의 겹구조: 조건이 공개되지 않은 언락(잃어버린 자, 포가튼, 승천 루트 등)이 커뮤니티 발굴 이벤트를 만든다. 발매 후 수년간 화제성을 유지한 원동력.

| 시드 플레이 | 시드 입력으로 던전 재현 (도전과제 비활성) | 공유/연습 |
| 승리의 한 바퀴 (Victory Lap) | 클리어 후 같은 빌드로 재시작 | 완성 빌드 감상 모드 |
| 로컬/온라인 코옵 (Rep+) | 최대 4인. 온라인은 퀵매치/친구매치/데일리, 부활 기계, 이모트 휠, 데스매치(언락) | 2024년 무료 업데이트로 추가 |

---

## 12. 연출 · 아트 · 사운드

- **아트**: 크레용/낙서풍 2D. 그로테스크한 소재를 귀여운 실루엣으로 중화 — 불쾌함과 귀여움의 균형이 브랜드 정체성.
- **피드백**: 피격 시 화면 흔들림, 적 사망 파티클(장기 파열), 아이템 획득 시 캐릭터 외형 변화(모자, 피부색, 눈 등 **획득 아이템이 외형에 누적 반영**) — 빌드가 시각적으로 '보이는' 것이 수집 욕구를 강화.
- **사운드**: 층 테마 BGM + 보스 테마. 아이템 획득 징글, 비밀방 발견음 등 **보상의 청각 각인**이 강함.
- **스토리텔링**: 로딩 화면 낙서, 엔딩 컷신, 배경 오브젝트로만 서사 전달. 시스템 플레이를 끊는 컷신/대사 없음.

## 13. 왜 재미있는가 — 핵심 재미 분해

1. **뽑기의 재미 (Variance)**: 매 층 아이템 추첨. "이번 판은 뭐가 나올까"라는 슬롯머신적 쾌감이 30초 단위로 반복.
2. **화학 반응의 재미 (Synergy)**: 아이템 2~3개가 얽혀 예상 밖의 괴물 빌드가 튀어나오는 순간 — 아이작의 시그니처 순간("갓런").
3. **선택의 재미 (Risk Management)**: 악마 거래, 저주 방, 자원 배분… "욕심"의 수위 조절이 실력.
4. **학습의 재미 (Mastery)**: 적 패턴, 비밀방 규칙, 아이템 지식, 알약 도감 — 지식이 곧 전투력. 위키를 읽는 시간조차 게임의 일부.
5. **발굴의 재미 (Secrets)**: 숨겨진 캐릭터/루트/엔딩. 커뮤니티와 함께 파헤치는 장기 콘텐츠.
6. **실패의 가벼움**: 한 판이 짧고, 죽어도 언락이 남고, 다음 판은 완전히 새 판 → "한 판만 더"의 무한 동력.

## 14. 모티브 게임 개발을 위한 시사점 (Design Takeaways)

우리 프로젝트가 아이작을 모티브로 할 때, 반드시 이식해야 할 뼈대와 주의점.

### 반드시 가져갈 뼈대 (우선순위순)

1. **방 단위 전투 + 절차 배치·수제 방 디자인** — 최소 구현: 방 그리드 생성기 + 방 레이아웃 30~50개면 프로토타입 성립.
2. **3층 루프 (방→층→런) + 명확한 보상 리듬** — 보물방(변화)과 보스 보상(성장)의 역할 분리까지 포함.
3. **무제한 스택 패시브 + 곱연산 시너지** — 아이템 개수보다 **상호작용 규칙의 일반성**이 중요. 30개의 아이템이라도 전부 중첩되면 조합 공간은 충분.
4. **체력을 화폐로 쓰는 리스크 거래** (악마 거래의 구조) — 아이작다움의 핵심 한 가지만 고르라면 이것.
5. **죽어도 남는 언락 (풀 확장형)** — 파워업 지급형(로그 레거시식)이 아닌 **다양성 확장형** 메타가 아이작식.

### 규모 조절 참고 (프로토타입 최소 스펙 제안)

| 요소 | 아이작 (풀버전) | 프로토타입 권장 |
|---|---|---|
| 아이템 | 717종 | 40~60종 (전부 중첩 가능하게) |
| 챕터 | 6챕터+대체경로 | 3챕터 6층 + 최종보스 1 |
| 방 레이아웃 | 수천 종 | 층당 15~20개 |
| 캐릭터 | 34종 | 2~3종 (규칙 변형 1종 포함) |
| 특수 방 | 20종+ | 보물방·상점·비밀방·악마방 4종 |
| 보스 | 100종+ | 층당 2종 풀 |

### 주의점 (아이작의 그늘)

- **정보 은닉 과다**: 위키 없이는 아이템을 알 수 없는 구조는 2010년대 감성. 게임 내 도감/획득 시 설명은 기본 제공 권장.
- **나쁜 뽑기 런의 무력감**: 아이템 운이 나쁘면 30분이 통으로 재미없어질 수 있음. 최저 보장 장치(층별 최소 1회 선택지 제공 등) 검토.
- **알약류 트롤 요소**: 순수 손해 랜덤은 호불호가 큼. 넣는다면 빈도를 낮게.
- **조작 이식**: Unity 구현 시 트윈스틱 조작(이동/조준 분리)은 필수. 4방향 고정 발사는 원작 감성이지만 자유 조준이 현대 표준.
