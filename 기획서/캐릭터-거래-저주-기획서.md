## 1. 악마/천사 거래 — "체력이 화폐다"

역기획서 8.2절의 핵심 리스크 시스템. 프로토타입에서는 별도 방 대신 **보스방에 거래 제단이 등장**하는 방식으로 구현 (룰은 동일, 공간만 축약).

### 1.1 등장 규칙

| 규칙 | 값 |
|---|---|
| 등장 시점 | 보스 처치 직후, 보스방 하단에 제단 등장 |
| 기본 확률 | 35% |
| **노히트 보너스** | 이 층에서 피해를 받지 않았으면 +35% (망토 방어는 무피해 취급) |
| 🐐 염소 머리 보유 | 100% 확정 |
| 악마 ↔ 천사 | 악마 거래를 한 번이라도 하면 이후 **천사는 등장하지 않음** (원작 배타 규칙). 아직 안 했다면 50:50 |

### 1.2 가격 규칙

| 상황 | 지불 |
|---|---|
| 악마 아이템 (2개 제시) | **하트 용기 1개** (최대 체력 −2칸) |
| 레드 용기가 1개뿐이거나 유령 아이 | 소울 하트 3개 (6칸) |
| 둘 다 부족 | 구매 불가 |
| 천사 아이템 (1개 제시) | 무료 |

### 1.3 악마 풀 8종 (i81~i88)

| 아이템 | Q | 효과 |
|---|---|---|
| 😈 피의 계약 | 4 | 공격 +2 |
| 🗡️ 저주받은 검 | 3 | 근접 오라 피해 + 공격 +0.5 |
| 🦇 박쥐 날개 | 3 | **비행**(바위 통과) + 속도 +0.3 |
| 👹 악마의 눈 | 3 | 공격 +1.8, 딜레이 ×1.15 |
| 🖤 검은 심장 | 3 | 소울 하트 3개 + 공격 +0.5 |
| 🔥 지옥불 | 3 | 화상 눈물 + 공격 +0.8 |
| 🐐 염소 머리 | 4 | 악마/천사 제단 확정 등장 |
| 💀 사신의 낫 | 4 | 명중 시 3%+행운 확률 즉사 (보스 제외) |

### 1.4 천사 풀 6종 (i89~i94)

| 아이템 | Q | 효과 |
|---|---|---|
| 😇 후광 | 3 | 공·연사·속도·체력 소폭↑ |
| 🕊️ 성스러운 날개 | 3 | 비행 + 소울 1개 |
| ✨ 축복 | 2 | 소울 2개 + 행운 +1 |
| 📿 묵주 | 2 | 연사 +0.7 + 소울 1개 |
| ⚔️ 성검 | 3 | 공격 +1.5 + 행운 +1 |
| 🌟 신의 가호 | 4 | 사망 시 부활 + 전체 회복 |

> 설계 의도: 악마 = 공격력과 이동의 질적 도약(비행·즉사·오라), 천사 = 생존과 안정. "강해지는 대가로 죽기 쉬워진다"의 원칙 유지.

## 2. 캐릭터 시스템 — 규칙 변형 4종

역기획서 6.3절: 캐릭터 = 스탯 프리셋이 아니라 **게임 규칙의 변형**. 시작 시 선택 화면(1~4 키).

| 캐릭터 | 유형 | 시작 스펙 | 규칙 변형 |
|---|---|---|---|
| 😐 이삭 | 표준형 | ❤️×3, 💣3 🗝️2 5¢ | 없음 (기준점) |
| 🎀 막달레나 | 체력형 | ❤️×4, 속도 −0.3 | 시작 액티브: 엄마의 약상자 |
| 🎩 검은 아이 | 고화력 유리몸 | ❤️×1, 15¢ | **공격 ×1.35**, 속도 +0.1 |
| 👻 유령 아이 | 소울 전용 | ❤️×0 + 💙×3, 연사 +0.2 | **레드 하트 사용 불가** — 체력업 아이템이 소울 하트로 전환, 악마 거래는 항상 소울로 지불, 회복 불가(소울은 소모성) |

- 사망 화면에서 `R` = 같은 캐릭터로 재도전, `C` = 캐릭터 선택으로.
- 유령 아이는 원작 ???(블루 베이비)의 규칙 변형 오마주 — 경제(회복 수단)가 완전히 달라진다.

## 3. 저주 시스템 — 정보를 빼앗는 난이도 변주

역기획서 4.3절. B2부터 층 진입 시 **25% 확률**로 1종 발동 (시드 결정적). HUD에 저주 표시.

| 저주 | 효과 |
|---|---|
| 🌑 어둠의 저주 | 플레이어 주변만 보이는 시야 제한 (비네트) |
| 🌀 상실의 저주 | 미니맵 완전 비활성 |
| 🙈 눈멂의 저주 | 받침대 아이템이 ❓로 표시 — 집기 전까지 정체 불명 |
| ❓ 미지의 저주 | 체력 HUD 숨김 |

> 전투력이 아니라 **계획 능력을 공격**한다는 원칙. 저주층의 보상은 그대로이므로 리스크만 상승.

## 4. 소모품 — 알약 & 카드 (Q 슬롯)

### 4.1 알약 — 판마다 섞이는 색-효과 매핑

- 6색 (🔴🔵🟡🟢🟣⚪) ↔ 6효과가 **런마다 시드로 재배정**. 처음 먹을 땐 도박, 이후엔 지식 (HUD에 알아낸 효과 표시).
- 효과: 기운 회복(2칸) / 힘이 불끈(공격 +0.4 영구) / 전력 질주(속도 +0.2 영구) / 눈물샘 자극(연사 +0.2 영구) / 복통(1칸 피해) / 용돈(+5¢)
- 트롤 효과는 1종만, 경상 수준 (역기획서 14장 주의점 반영).

### 4.2 카드 — 앞면 공개 소모품

| 카드 | 효과 |
|---|---|
| ☀️ 태양 | 전체 회복 + 층 전체 맵 공개 |
| 💀 죽음 | 방 전체 적에게 40 피해 |
| 🗼 타워 | 폭탄 +3 |
| 🃏 광대 | 시작 방으로 순간이동 |

### 4.3 규칙

- 소지 1개 (Q로 사용, 새로 주우면 교체). 적 처치 시 알약/카드 각 2% 드롭, 상점 판매(4¢), 아케이드 경품.
