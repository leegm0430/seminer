# 🎒 아이템 시스템 기획서 (v2 — 80종)

> 아이작의 번제 아이템 구조(tboi.com / 나무위키 패시브 아이템 문서 참조)를 기반으로 한 **오마주 + 오리지널 변형** 설계.
> 유명 아이템의 '효과 구조'는 가져오되 이름·컨셉은 우리 게임용으로 재창작 — 추후 출시에도 문제없는 방향.
> 이 문서의 수치가 단일 소스이며, 데모(`isaac-prototype.html`)의 `ITEMS` 배열과 1:1 대응한다.

## 1. 시스템 규칙

### 1.1 데이터 스키마 (나무위키 문서 구조 채택)

| 필드 | 설명 |
|---|---|
| `id` | 내부 식별자 |
| `name` | 한국어 이름 (오리지널) |
| `hm` | 오마주 원본 (아이작 원작 아이템) |
| `type` | passive / active / familiar |
| `pool` | boss / treasure / shop / secret |
| `q` | 퀄리티 0~4 (아이작 Repentance 방식) |
| `fx` | 효과 스펙 (엔진이 해석하는 구조화 데이터) |

### 1.2 스탯 공식 (데모 엔진 기준)

- 공격력 = (3.5 + Σdmg) × Πdmgmult
- 발사 딜레이 = max(5프레임, 24 / (1 + Σtears)) × Πfdmult — 연사에 체감 곡선 적용
- 이동속도 = min(6.0, 3.4 + Σspeed×1.0)
- 사거리 = 260px + Σrange / 탄속 = 5.5 + Σshot / 행운 = Σluck (드롭·발동률 보정)
- **모든 패시브는 무제한 중첩, 눈물 변형 플래그는 전부 동시 적용(곱연산 시너지)** — 역기획서 7.4절 원칙

### 1.3 아이템 풀 & 지급 규칙

| 풀 | 등장처 | 성격 | 수량 |
|---|---|---|---|
| boss | 보스 처치 보상 | 스탯 업 중심 (확실한 성장) | 14종 |
| treasure | 보물방 (열쇠 필요) | 눈물 변형·패밀리어 (빌드의 축) | 20종 |
| shop | 상점 (15센트, 회원권 시 반값) | 유틸·경제·액티브 | 11종 |
| secret | 비밀방 | 전 풀 고급품 혼합 | 5종 |

- 한 번 등장한 아이템은 해당 런의 풀에서 제거(중복 방지). 풀 소진 시 미획득 아이템으로 재충전.
- 악마/천사 풀은 2차 확장 예정 (체력 지불 거래 시스템과 함께).

### 1.4 액티브 아이템 규칙

- 1개 슬롯. 새 액티브 획득 시 기존 것과 교체(받침대에 내려놓음).
- 충전: 방 클리어당 1칸. 충전 완료 시 Space로 발동.

## 3. 시너지 규칙 (구현 스펙)

- **플래그는 전부 동시 적용**: 유도+관통+반사+독+분열이 한 눈물에 공존 가능.
- 멀티샷(겹눈/제3의 눈/유성우)은 **발수 합산, 배율 곱연산**: 겹눈+제3의 눈 = 4발.
- 분열 눈물은 부모의 플래그를 상속하되 재분열 금지 (무한 증식 방지).
- 화약 눈물(폭발)은 플레이어에게도 피해 — 리스크 내장형 고화력의 원칙 유지.
- 달팽이 점액(공격×0.25)과 외눈박이(공격×2+2)의 조합처럼 **배율 아이템 간 상쇄/폭발 조합**이 성립하도록 가산→배율 순서로 계산.

## 4. 밸런스 가드레일
